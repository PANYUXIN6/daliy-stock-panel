## 本地样本诊断与参数取舍

只读核对了300561.SZ、600519.SH、000001.SZ、600036.SH、300750.SZ、002594.SZ、601318.SH、000300.SH。已存完成日K分别约242—259根，截止到2026-11-03；这些是诊断样本，不是独立人工正负样本。

- 汇金科技原算法在本地得到12.57—22.47元的未突破大框；新算法在该截止日无默认活跃框，仍保留其他已结束结构供历史查看。本地数据少于用户截图，不能声称精确复现截图的391根结构。
- 平安银行11.27—11.85元、比亚迪81.72—86.69元的近期窄幅结构仍进入活跃候选集。比亚迪同时保留78.71—95.72元历史参考，默认不填充该历史大框。
- 对比三组ATR上限（触碰／离开／突破）：0.75／1.0／0.5、1.0／1.25／0.75、1.5／1.75／1.0，八个标的的当前日线活跃数量一致。采用中间组作为工程默认值，不能据此宣称最优；带偏差的合成触点另验证了最终区域过紧时不会错误确认。
- 周线比较8／20、12／26、16／32根窗口；汇金科技3个未突破周线结构分别有0、1、2个活跃，其余样本未出现活跃周线。采用12／26作为独立周线初值，兼顾多次往返所需周期与过期；此比较只说明敏感性，不构成质量评级。
- 月线比较6／12、8／18、12／24均无成立结构，现有真实历史不足以校准月线活跃性。采用8／18作为独立工程初值；已有多年月线、包含慢速往返的独立参考样本时，应重新评估该组参数。

同一环境和同一日K样本的单次纯算法耗时，旧实现约9—11毫秒、新实现约11—16毫秒；这是局部开销观察，不是压力测试。未增加供应商调用、持久化或后端结果缓存。

## 复核入口

后端运行箱体检测、活跃性、服务、评估和既有快照测试；前端运行共享个股图、指数页、图表与面板测试，并执行构建。页面以只读本地结果检查桌面与390像素容器：无活跃框、活跃分段、详情换行、历史开启及缩放参考线。

在 `backend/` 下复核已有合成快照，输出路径须尚不存在：

```bash
uv run python scripts/evaluate_box_oscillation.py baseline --output /tmp/box-baseline.json
```

参考规则见[算法与活跃性契约](box-oscillation-design.md)及[结构核对说明](box-oscillation-evaluation.md)。今后的独立人工核对应同时观察误识别、漏识别和过早降级，不能仅以异常大框消失作为质量结论。

此次更新不仅替换期望值：三个突破场景的尾部收盘价同步移到新的区域外沿及缓冲之外，继续覆盖待确认、回箱、向上／向下连续两收盘突破。第一条候选样本已有细粒度触点，但实际长度不足15根，仍不能确认。对应行为另由纯算法测试验证，避免快照自行证明正确。

当前触碰区域为种子上下沿±原始箱高20%；离开距离24%、重复合并20%独立配置。日线保留2/2主拐点并补1/1细拐点，最短15根及30／60分组不变；周/月沿用各自长度与1/1拐点。候选代表价取区域内独立已确认触点中位数，确认后冻结。突破使用固定区域外沿+原始箱高5%缓冲、同方向连续两收盘。近期反应跨度需保留原始跨度70%，以排除明显收敛。

验证覆盖同日触点去重、边界冻结、孤立影线、历史与在线退出一致、嵌套和趋势排除。检测、服务、评价与既有快照共 **83项通过**。真实旧样本另外逐一回放首次确认日及前一根截止日，核对已确认身份、边界与确认日期不随未来数据改变；这不替代新样本的独立结构核验。

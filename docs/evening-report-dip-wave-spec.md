# 每日晚报波次与低吸判断规格

本规格约定交易日收盘后可以确认哪些波次、何时关闭首波窗口、如何给出低吸三档，以及离线研究如何评价已发布的启动。它是未提交实现的整改依据。题材、角色、名额和个人记录见[名单与归档设计](evening-report-optimization-plan.md)，输入就绪与发布见[盘后流程](postmarket-pipeline.md#每日晚报的就绪定稿与回看)。

## 1 输入与计算范围

目标交易日为 D。对每只范围内股票取截至 D 的固定近窗，同一套规则使用同一长度，范围为 120～250 个市场交易日。首版取 250 日，以减少从窗口左端开始识别结构时丢失的历史。上市较晚时只从首根实际日线起算。按日顺序运行同一个确定性 ZigZag 函数，输入只含日期不晚于当前推进日的事实。D 的波次和启动只取当日窗口的计算结果。250 日窗口左端自然滑出可能改变初始摆动及其后推导的确认日，接受这种差异，不与前一窗口对齐或回查旧报告。换参数从下一份未发布晚报生效，报告头记录所用规则和窗口。

股票资格取 D 的正式证券元数据。ST 不进入当日观察范围。摘帽后使用常规非 ST 计算，沿用正式日线和均线。正式行情、因子、指标与本地标准交易日历的验收归上游。晚报只读这些数据，独立处理影响当前判断的缺项。共同的单位与复权约定见[维护约定](../CONTRIBUTING.md)。

## 2 价格、样本与参数

正常盘后正式仓最新交易日为 D，此时已验收的 `enriched` 价格和均线就是 D 基准的前复权序列，波次、收益与支撑直接取用。晚报不另行换算全市场 250 日行情。收盘涨跌停、连板与交易所价格限制用相应交易日的原始价及既有规则。成交量采用同一单位，成交额以元计。比例内部使用小数，页面显示百分比。

| 判断 | 初值与比较方式 |
| --- | --- |
| ZigZag 反转 | 相对候选极值的收盘反向幅度 ≥5% |
| 首段幅度 | 已确认的 H1/L0 − 1 ≥20% |
| 首段量价证据 | 收阳且成交量 ≥此前 20 日均量的 1.5 倍，或收盘严格超过此前 20 日最高价。两项窗口均不含证据日 |
| 回调质量 | 回撤占上涨段的 25%～75%，含两端。回调均量严格小于上涨段均量，且回调至少有 2 个实际交易样本。L1 未确认时按截至 D 的回调区间判断 |
| 支撑 | 收盘距 MA10、MA20 或多空线任一条 ≤3%（绝对值）并有止跌证据，或连续三日低点严格抬高 |
| 第二段放量 | 当日量 ≥回调均量的 1.3 倍，且 ≥前一上涨段均量的 0.8 倍 |
| 首波低吸的当前回撤 | 1 − C(D)/H1 ≥5%，且首波窗口仍开放 |

## 3 收盘确认与候选极值

从窗口首根有效日线起跟踪候选高点。首次收盘自该高点回落达到阈值，证明已观察到下行，从下一有效日开始跟踪候选低点。随后收盘自候选低点反弹达到阈值才确认低点 L0。窗口左端的最低价本身没有确认效力。窗口内尚无足够摆动时显示“首段待确认”。

设反转阈值为 Z，初值 0.05。向上寻找高点时用盘中最高价更新候选 H，收盘 ≤H×(1−Z) 时确认高点。向下寻找低点时用盘中最低价更新候选 L，收盘 ≥L×(1+Z) 时确认低点。相同极值沿用最早日期。一根日线最多确认一个方向，反向候选从下一有效交易日开始。极值日描述高低价发生在哪天，确认日决定最早哪天可以使用它。后续极值不能移动已确认点，更不能改写旧晚报。

当前候选只需方向、价格、极值日和距上次严格更新的有效交易天数。**横盘不设静置过期**。超过 20 日仍保留候选，直到价格确认反转或结构失效。静置天数只描述现状。无需保存每日候选移动历史，也无需设计过期后的重连。

## 4 首段、回调与结构失效

L0 之后的第一个已确认高点 H1 达到首段幅度才建立第一段。幅度不足时保留普通摆动，等待新的低点与随后高点，不能跨越中间摆动拼成一段。首段量价证据在 [L0 极值日, H1 极值日] 内逐日判断。“或”的一条分支已知成立即通过。结构计数与量价质量独立。

H1 之后首个已确认且高于 L0 的回调低点为 L1。收盘严格跌破 L0（已有结构回调低点时用最近的 Lk）结束该轮。等于失效线时仍有效。后续普通摆动低点不会替换已确定的 Lk。新轮次须重新满足首段条件。

上涨段均量取 (L0 极值日, H1 极值日]。H1 已确认且首波窗口开放时，按 D 日可知的结构选择回调区间，同时判定回撤与缩量。

| D 日已知状态 | 质量判断用的回调区间 | 回撤占上涨段的比例 |
| --- | --- | --- |
| L1 未确认 | (H1 极值日, D] | 用区间内已观察到的最低价 P 计算 (H1−P)/(H1−L0) |
| L1 已确认 | (H1 极值日, L1 极值日] | 用已确认的 L1 价格计算 (H1−L1)/(H1−L0) |

两种状态均用对应区间的实际成交日算回调均量。至少 2 个有效样本且均量严格小于上涨段均量时，缩量通过。样本不足或必要量价缺失时，对应项待核验。L1 未确认时算出的回撤与缩量可直接参与当日 `full` 判定，详情标明区间截至 D。5% 反弹仍用于确认结构低点和判定第二段启动，后续确认不能改写此前定稿。

门⑤另用当日收盘判断距 H1 的回撤。例如 L0=10、H1=12、L1=11 时，上涨段回撤比例为 50%。若 D 收在 11.55，当前距 H1 仅 3.75%，当日不具备首波低吸资格。

支撑的贴线分支还要求当日低点不低于前一交易日低点且当日收盘 ≥开盘。另一分支要求连续三个市场交易日低点严格抬高。任一已知成立即可。缺失某一条均线只影响依赖它的比较。

## 5 第二段启动与首波窗口

首波窗口在首段已确认、结构有效时开放。只有 H1 和 L1 均确认后，第二段才可能正式启动。在 L1 极值日之后，取首个同时满足以下两项的合格证据日 E。

- 收盘严格高于当日 MA10，或严格突破回调平台。平台取 (H1 极值日, L1 极值日] 的最高收盘，在 L1 确认时固定。
- 当日成交量同时满足两项启动倍数，且截至确认时结构仍有效。

若 E 早于 L1 确认日，只能在 L1 确认后、当日收盘仍满足对应价格分支时登记启动。K 为启动首次正式成立的交易日。在 D 的窗口内，每只股票每轮只取首次成立的第二段启动，仅当 K=D 时写入 D 的定稿。段高确认日是该段首次登记的最后机会。在该日先判启动，再确认段高。多日重复达标、发布重试均只对应同一启动。

量价启动或 L1 确认后收盘严格超过 H1，任一成立就关闭本轮首波窗口。弱量创新高也进入第二段。随后回落或启动评价失败不能重开。量价启动、结构创新高、反转确认段高是三件事。若同一收盘既突破前高又确认新段高，当日先推进段编号，再计完成段数。第三段及以后继续按对应锚点计结构段数，启动登记及效果评价止于第二段。

## 6 停牌、缺口和补齐

确认全天停牌时跳过该日波次推进、极值计龄和段均量，当日不发低吸信号。复牌仍对比停牌前的候选极值。例如候选高点 20、停牌前收盘 19.2、复牌收盘 18.9，收盘相对候选回落 5.5%，已达到反转阈值。

无停牌证据的缺行影响结构连续性时，该股当期为 `data_gap/unknown`。只有量能或某项指标缺失时，保留仍可确定的价格结构或其他独立条件。补齐后用完整近窗算到最新 D，只登记在 D 新成立的启动。例如，周二缺行、周四补齐，若启动按日线应在周三成立，周四可显示窗口已关闭，周三和周四的新增启动数均不因这次补齐而增加。中间缺报同理。

## 7 五道门与低吸三档

低吸表示“严重异动相关的首波回调”。只对观察名单及同口径可比候选作标签。五道共同门、截至 D 的首波质量和 E1/E2 路径形态分别判定。

| 门 | 条件 |
| --- | --- |
| 环境 | 退潮（`phase=ebb`）或 `cold` 禁止。`hot_fragile` 显示风险提示 |
| 地位 | 龙头通道要求空间分 ≥50、辨识度 ≥45、高点接近度 ≥85%。情绪通道要求有情绪属性、辨识度 ≥60、20 日涨幅 ≥20%。首波加速通道要求窗口开放、当日首波质量通过、10 日涨幅 ≥30%、5 日涨幅 ≥3%、高点接近度 ≥85%。三条取其一 |
| 承接 | D 日成交额在 10%／20% 制度下分别 ≥5 亿／8 亿元。首波质量及人气加速达标可分别用 2.5 亿／4 亿元。标准档独立有效 |
| 情绪配合 | 市场二板及以上家数 >0。零为已知不通过，未知保留待核验 |
| 首波回调 | H1 已确认、首段幅度达标、结构有效、窗口开放且当前回撤 ≥5% |

E1 需当日适用“即将严重异动”事件，同时检查 3 日涨幅 ≤15%、2/10 日量比 ≤0.65、距 MA10 在 [−2%, +6%] 和 2/10 日振幅比 ≤1.2。E2 需当日适用“已发生严重异动”事件，同时检查 2/10 日量比 ≤0.55、最近两日不创新低、距多空线绝对值 ≤5%。

E2 的低点只比较 D 与前一市场交易日 D−1 的同基准前复权最低价。L(D) ≥ L(D−1) 通过，平底也通过，跌破则失败。任一日停牌或缺少有效低点时该项待核验，不向前跳日。这一项与第 4 节的首波支撑分别判断。

量比、振幅比均用最近两日均值除以此前不重叠的十日均值，日振幅为 (H−L)/前收盘。零分母、窗口缺行或含停牌影响比较时，该项待核验。E1 的 MA10 距离区间和 E2 的两日低点比较各算一项形态条件。

| 档位 | 判定 |
| --- | --- |
| `full` 完全符合 | 五道门及当日首波质量（首段幅度及量价证据、按第 4 节取值的回撤与缩量、支撑）全部通过，且至少一条事件适用路径的形态全部通过 |
| `partial` 部分符合 | 五道门均已知通过，至少一条有适用事件的路径有一项实际形态通过，但当日首波质量或该路径形态尚未全部通过 |
| `none` 无低吸点 | 其余情况。共同门失败或未知、没有适用事件、仅有形态未知，均不能升级为部分符合 |

每项指标保留原值、阈值、单位与通过／未通过／未知／不适用。缺失写 `null`。行内给一个便于理解的主要原因。通过时显示“完全符合”。七类主原因分别为环境或市场情绪禁止、非首波或窗口已关闭、当前回撤不足、地位或成交额不足、无适用异动事件、形态或量价质量未满足、停牌或资料待核验。优先解释已知禁止与必要门失败，随后解释必要资料缺失、事件及形态。详情可列同日其他检查。T4 待核验和表已完成但无事件，在文案和状态中分别表达。主原因不承担对所有字段状态排列组合的编码。

## 8 严重异动事件（T4）

未来由盘后同步或按交易所公开偏离规则计算一张日频事件表，按证券、适用交易日、路径（E1/E2）读取。该日同步或计算成功即视为完整，有适用记录即进入对应形态判断，无记录为 `no_applicable_event`。尚未接入、当日任务失败或尚未完成时，事件前置为未知。事件修订链、多来源互证、对空记录反向举证和公告分钟与晚报截止时刻的先后均不属于此契约。T4 正式来源完成前，近似偏离度只供展示，E1/E2 均不能给出 `full` 或 `partial`。

## 9 定稿保留的事实

报告头统一记录 `trade_date`、价格基准日 `as_of`、名单及波次／低吸规则标识。个股只存解释当日判断所需的已确认锚点（极值日、确认日、当时前复权价、相应原始价）、当前候选、结构段数、窗口状态和低吸明细。无需逐点保存因子乘数、文件指纹、来源时间或候选移动流。

当天新成立的第二段启动作为日频事实保留，涵盖未入选证券。最小记录能定位证券、启动、E、K，并固定 `target_high=H1`、`failure_low=L1`、K 日低点及收盘，价格统一到 K 基准。研究从已发布记录取这些起点。其余日期的行情、因子与日历由离线任务直接读取。波次、低吸及启动详情所需事实都随当期定稿保存，不生成 `context_refs`。离线研究需要其他日期的报告时按交易日直接读取。

## 10 离线启动评价（T5）

从已发布晚报取第二段启动，按既有启动键 `(security_id, start_id, rule_version)` 去重。同键出现多次时采用最早定稿的 K 和冻结锚点。用评估时本地正式日 K 和因子，将后续收盘转到冻结锚点的 K 日基准。以项目累计因子 F 表示时，比较价为原始价 × F(t)/F(K)。价格使用交易日对应的累计因子，单次除权事件因子不能直接代入。

K 收盘已严格超过目标的样本单列为“启动时已突破”，不计作前瞻成功。其余只按本地标准交易日历逐日比较 K+1…K+10 的收盘与启动自身的固定价位，按首次命中确定结果。

| 价格事实 | 评价 |
| --- | --- |
| 收盘严格低于 failure_low，或突破目标前严格低于 K 日低点 | 失败 |
| 收盘严格高于 target_high | 窗口内突破成功 |
| 窗口内未命中上述条件，且 K+10 收盘相对 K 收盘涨幅 ≥8% | 期末收益达标 |
| 完整走到 K+10 仍未达标 | 到期未达标 |

盘中触线和窗口中途上涨 8% 均不能替代相应收盘条件。已知收盘等于高低锚点不触发突破或跌破。尚无决定性结果且观察期未满，或日历尚未覆盖待评交易日，标 `not_due`。已经过的观察日若缺少必要价格、因子或遇停牌，致使首次命中顺序无法判断，标为不可评价，不顺延、不跨过缺口猜测。只用价格判终态，不订阅波次的 `structure_invalid` 事件或比较获知时间。

研究单列样本总数、起点已突破、未到期和不可评价数。比较前瞻结果时，分母只取观察期已满、起点未突破且路径可评价的启动。分母为零时比例为 `null`。可用同题材、同名额的基线对照已发生的价格表现。统计比例只描述该批历史样本，研究重跑只更新离线结果。

## 11 验收与审查边界

| 用例 | 应观察到的结果 |
| --- | --- |
| 输入序列含 D+1 的新极值，但只计算截至 D 的结果。正常重试后用最新就绪输入定稿 | D 只采用最终验收中截至 D 的数据。未来极值不能移动 D 已确认的点，重试只发布一份 |
| 除权、停复牌、已确认低点后弱量创新高 | 前复权骨架在同基准判定，涨跌停沿用原始价。停牌不作破位或缩量，弱量创新高仍关闭首波窗口 |
| 一股缺行后补齐，或一股缺少涨停事实 | 波次局部待核验，补齐后只登记 D 新启动。题材对有效成员累加并披露缺数，其余股票正常出报 |
| 概念及其余必需数据齐全，自动盘后行业失败或手动准备跳过行业 | 两条路径均发布概念名单，行业显示缺失。自动主管道保留行业失败。若缺的是本轮概念分类，则不能用旧概念出报 |
| L0=10、已确认 H1=12，L1 尚未确认。H1 后两个成交日低点均为 11.20、成交量分别为 50 和 60，上涨段均量为 100，D 收在 11.30 | 截至 D 回撤占上涨段 40%，回调均量 55，当前收盘距 H1 约 5.83%。若支撑、其余共同门、质量及一条适用事件路径全部通过，当日为 `full`，第二段仍未启动。回调仅有一个成交样本时，缩量待核验，不能给 `full` |
| E2 的 D−1 最低价为 10.00，D 的最低价分别为 10.00、10.10、9.99 | 低点项依次为通过、通过、失败，均无需比较 D−2 的低点。D−1 停牌或缺低点时该项为未知 |
| T4 未接入、日频表已完成但无记录、具有适用事件三种输入 | 前两种均不能给出部分或完全符合。前置未知与无适用事件可区分。有事件时按各自路径及共同门计算 |
| 同日自动与手动请求、任务跨午夜、读取旧定稿 | 一日一个归档标识。已提交且输入齐全的任务按原 D 完成。历史 GET 只读请求的定稿，已发布归档缺失或损坏时返回 `missing` |

本功能的问题只有**同时满足三项条件**才列为 P1/P2。报告时给出触发输入、预期与实际结果，并说明局部降级为何不足。

1. 日常增量同步、真实盘后补缺、正常重试或页面读取即可复现。
2. 会选错股票、算错波次或低吸、重复发布、破坏已定稿报告，或使合法输入无法出报。
3. 无法通过对单股或单字段标记 `unknown` 隔离。

人为删改或截断内部文件、对已定稿历史改价、同日验收字段先后及临时撤回、跨年停采的日历拼接、构造的同批矛盾报价或坏因子、叠加多个低概率故障，均以读取告警、局部缺失、接口不 500 和任务不中断为边界，不为这些场景扩写状态机或专项测试。交易日因果、价格单位、原子写入与一天一份定稿仍是验收条件。

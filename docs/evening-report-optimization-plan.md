# 每日晚报的观察名单、归档与个人记录

晚报按交易日给出值得继续观察的题材和股票。一天发布一份，历史页展示当日定稿的入选理由和顺序。名单使用 `theme-observation-v2`，波次、位置和低吸只为入选与可比候选提供标签。本文与[波次与低吸规格](evening-report-dip-wave-spec.md)是当前开发目标。未提交实现中仍有旧的验收、回放和存储路径，不能据此认定已完成整改。

## 输入与责任

| 数据或结果 | 责任边界 |
| --- | --- |
| 股票池、正式日 K、复权因子、指标、交易日历 | 主管道负责采集、标准化、发布和当日完整性验收。晚报只读正式仓及共享指标 |
| D 日证券资格、概念成员、停牌、市场环境与情绪 | 使用本轮正式结果和对应交易日。历史题材或身份不能用今天的分类填补 |
| 晚报是否可生成 | 看 D 的就绪记录与 `stock_generation`。当日定稿前重验覆盖同一个原子 JSON，只认发布采用的最终输入 |
| 名单、波次、低吸、定稿 | 晚报服务按规则一次计算，API 读取归档。页面筛选只改变可见行 |
| 个人反馈、客观回看、离线研究 | 分别管理账号标记、推荐后的价格表现和研究结果，任一失败都不影响共享晚报定稿。选股、排序和低吸只依赖对应版本的规则与正式输入 |

所有窗口按北京时间的实际交易日。D 日计算只用截至 D 已知的数据。日线与指标直接消费 `kline_daily` 和 `enriched`，同股同日重复行按源记录顺序在写入或读取边界稳定保留最后一行（`keep='last'`）。非正或非有限因子在读取时排除，使无法换算的本股当期值为未知。正常无除权事件按既有因子口径处理。因子恢复后重新读取当期有效数据，无需跨批维护恢复记录或近 20 日全市场涨跌停凭证。历史价格限制复用 [price_limits.py](../backend/app/price_limits.py) 及相应交易日的指标。涨跌停基于原始价，收益、波次和均线基于同基准前复权价。

`require_ready` 只核对目标交易日就绪标记及股票指标代次。上游未通过当日必需输入验收，晚报等待。通过后，单股或单指标缺数只影响实际依赖它的判断。历史某日缺行仅影响附近依赖窗口，随后有效的 ATR14、多空线等继续使用正式指标。晚报不再逐行比对两套价格、不对全市场复算共享指标，也不将全部历史分区的大小与修改时间作为就绪条件。盘后步骤与失败隔离见[盘后约定](postmarket-pipeline.md#每日晚报的就绪定稿与回看)。

## 市场环境与个股变量

市场摘要复用同日[市场情绪服务](../backend/app/services/market_sentiment.py)和原有六阶段，保留未归类或未知状态。市场统计使用共享服务的股票范围和 ST 设置。摘要展示温度、承接质量、变化方向、周期阶段及综合标签。

- 温度按涨停家数在 40、60 家处分档，封板质量按炸板率在 25%、35% 处分档。涨停与炸板使用同一触板集合，零分母为未知。晋级率、跌停家数及昨日炸板股表现另作说明。
- 昨日涨停集合在前一交易日固定，今日溢价为两端可评价股票的等权收盘收益。停牌单列，有效样本不足 10 或非停牌缺数时不用于确定性溢价判断。方向比较今日与此前 5 日均值，涨停家数变化 5 家、炸板率变化 3 个百分点、溢价变化 0.5 个百分点分别投票，三票齐全且两票同向才确定改善或恶化。
- 综合标签沿用共享结果 `hot_fragile/hot/warm/cold/repair/mixed/unknown`。退潮或 `cold` 只限制低吸，`hot_fragile` 提示承接风险。大面与亏损扩散尚无可核实的统一定义（T1），不参与判断。

| 名单变量 | 口径 |
| --- | --- |
| N 日收益 | C(D)/C(D−N)−1，取固定市场交易日端点。端点停牌或缺价时未知，不移动日期 |
| 辨识度 `identity_score` | min(100, 近 20 日收盘涨停次数 ×18 + 当前连板数 ×14) |
| 空间分 `space_score` | min(100, 20 日收益 / 0.80 ×100) |
| 高点接近度 `high_proximity` | D 日收盘 / 最近 60 个交易日最高价。窗口不足时未知 |
| 加速比 `acceleration_5_20` | 5 日收益 / 20 日收益。分母须为正。只用于情绪股资格及说明 |
| 多空线、距离、成交额 | 多空线沿用 EMA10((H+L+C)/3)。距均线为 C/均线−1。当日成交额用元，近 20 日成交额中位数单独展示 |

变量的公式、单位和共同规则版本只定义一次。每股保存实际用到的数值与检查状态，依赖项未知时写 `null` 并说明缺项。各个“或”分支独立判断，已知成立的分支不受无关缺项影响。

## 题材强度与缺数

使用 D 日本轮完整概念成员，在固定集合上回看 D−4 至 D。按原始完整成员数排除超过 120 只的宽概念，恰好 120 只仍可参与。地域、通道、指数成分、风格及虚拟复盘标签按明确的完整标签排除。行业只供背景展示。概念输入及其余必需数据就绪时，即使行业分类缺失，也照常发布概念名单并显示“行业缺失”。主管道单独报告行业步骤失败。相邻分类增删（`classification_comparisons`）只供参考，缺前值或来源语义改变时记首次观测。前值缺失不阻断晚报。

题材 s 在 D 的强度为 `Σ(k=0…4) 2^(−k/2.5) × [U(s,D−k) + 0.5 × S(s,D−k)]`。U 为收盘涨停家数，S 为未封板且当日涨幅 ≥7% 的家数，两组互斥。复牌日涨幅用停牌前最后有效收盘比较，中间须有全天停牌依据。已确认停牌的成员日跳过，不把停牌推断为行情缺行。

**按有效成员日累加**。涨停已知的成员直接计 U。已知未涨停且涨幅可判定的成员参与 S 的判断。缺少判定所需事实的成员日跳过，用 `missing_count` 记录个数（同股同日只计一次）。全部五日都无可用贡献判断时强度才为 `unknown`。有有效行情但都没达到贡献条件时为已知 0。最高连板从已知值取最大，缺连板数不会抹掉已知的涨停贡献。例如同日有一只涨停（3 连板）、一只未封板涨 8%、一只缺数，当日贡献为 1.5，最高已知为 3，缺数为 1。

强度为正的题材取前五，同分依次比较当日涨停数、最高已知连板及稳定题材标识。辅助值不足时保留其未知状态。成员可对多个题材贡献强度，最终股票只占一个名额。

## 角色、排序与配额

范围为沪深主板与创业板非 ST 普通 A 股。当日须有正常交易、证券资格允许观察和正式原始收盘价。主角色按下表由上至下取可证明的第一项。已知的低优先级角色可保留，并注明高优先级条件待核验。

| 当日角色 | 条件 |
| --- | --- |
| 真龙 | 20 日收益 ≥50%、辨识度 ≥45、高点接近度 ≥85% |
| 兜底龙 | 20 日收益 ≥30% 或辨识度 ≥30 |
| 情绪股 | 5 日收益 ≥12%、加速比 ≥0.45、20 日收益 <55% |

当日真龙、当日兜底龙、仅有历史身份的待复核对象依次竞争龙头名额。历史真龙当日仅满足兜底时，以兜底龙参与一次竞争。情绪属性可作为副标签。仅靠历史身份跟踪者标“历史龙头待复核”。T3 定义失效规则前，历史真龙跟踪只保留最近 5 个交易日（D−4 至 D，含两端）内满足过当日真龙条件的证券。仅当再次满足真龙条件时才更新最近真龙日，待复核、获配名额或降为兜底均不续期。

综合领先分由 `evening_report_observation.py` 计算。比较组取 D 日该概念内符合本节当日观察资格、且 5 日和 20 日收益均可按固定端点计算的全部成员，含本股至少 6 只。计算领先分时，60 日高点接近度是个股得分分量。比较组不另设 60 日预热、连续 21 根日线或 20 日成交额中位数门槛。整改时从生成链移除旧引擎的 `_prepare`、`_build_sectors` 及其路径、核心身份和韧性评分。

1. 先确定唯一主题材，取入围题材中排序最高者，其余只作关联标签。每题材最多 2 个龙头名额（主板或创业板），1 个情绪名额（仅创业板）。允许空位，不跨题材或角色补足，总数最多 15 只。
2. 真龙、兜底龙各自在同日、同主题材、同角色档位内排序。全组领先证据完整且可比时，取综合领先分，再比辨识度、20 日收益、高点接近度。综合分为 0.5×20 日相对收益百分位 + 0.3×5 日相对收益百分位 + 0.2×60 日高点接近度标准化分。每个期限先取其余成员同期收益的等权均值 B，再算本股相对收益 (1+本股收益)/(1+B)−1。在含本股的完整比较组内取 0～100 百分位，同值取平均名次。接近度按 0.85～1 线性映射到 0～100 并截断。
3. 比较组不足 6 只，或同一角色档任一竞争者缺少得分分量、口径不可比，该角色竞争组统一改用组内 20 日收益排名作领先项。相同收益并列，未知排在已知之后，记录回退原因与可比数。排序方式在分配名额前确定。单股缺数不会使同组其他股票失去资格。
4. 历史待复核档依次比较辨识度、20 日收益、高点接近度。情绪股依次比较 5 日收益、辨识度、高点接近度。客观排序全同再用创业板偏好、证券代码稳定排序。报告按题材排名、龙头在前、情绪股在后展示。

报告行写明“为何得到这个名额”，包括实际角色、主题材、名额内分配前排名与所用排序依据。位置、成交额档位、波次及三档低吸均独立展示，无权反向改变名额。严重异动前置、五道门和主原因以[低吸判定](evening-report-dip-wave-spec.md#7-五道门与低吸三档)为准。

## 定稿、读取与存储

| 对象 | 保存与读取 |
| --- | --- |
| 盘后就绪 | D 一份原子 JSON，含本轮就绪状态、股票指标代次与生成所需的当日输入。成功重验直接替换，定稿后无需重放 |
| 正式晚报 | 每交易日一份，长期只读。报告头保存交易日、复权基准、归档与规则标识。正文保留市场、入围题材、入选顺序及理由、波次／低吸所需事实和 D 新确认的第二段启动 |
| 历史真龙 | 仅从上一交易日定稿继承 `role_state`，在 D 的定稿内保存仍在范围及上述期限内的“证券代码 → 最近真龙日”，涵盖未获配名额的真龙。上一交易日缺报、文件不可读或旧格式无此字段时，从当天满足条件的证券重新建立，不回查更早报告，也不单设滚动状态文件 |
| 名单审计 | 记录实际竞争与可比落选、名额、排名及必要缺数。既有精简审计和候选池边界按 730 天维护。入选和仅因配额落选的可比候选保留当日角色、竞争组、实际排序依据和决定。已有长期候选、历史报告与个人记录仍可读 |
| 到期维护 | 就绪和按需生成的诊断沿用 30 天、任务尝试状态 90 天。沿用现有维护任务和目录范围，历史行情、定稿及个人数据均不作为清理对象 |
| 客观回看、研究、个人反馈 | 分别写入共享回看结果、离线研究结果与账号记录。报告原件不接收后续追加 |

新写 JSON（含压缩归档）和 Parquet 均先写同目录临时文件，再用 `os.replace` 原子发布。写入互斥复用 collector 的既有写入槽，交易日作为发布唯一键。新定稿的报告详情全部来自当期归档，不生成跨报告上下文引用（`context_refs`）。GET 只读请求的归档，旧格式按自身已有事实展示，跳过旧引用。已发布报告的文件缺失、解压或解析失败时记录告警并返回 `missing`，其余日期仍可读。

未提交稿中的公共仓写入取证（`daily_revisions.py`、`repository.py`、`kline_sync.py` 的 diff／`price_writes`）、多批次价量回放与三阶段验收应在后续代码整改时移除，`flush_live_daily` 等公共入口保持原有语义。单日就绪取代暂存原件、验收索引及重建扫描。原子写入的内部文件不做深度格式复验或 inode 缓存。归档直接使用共享变量定义和逐股值，无需 `pack_report/unpack_report`。晚报不提供自动分桶自学习、胜率反哺或相应扩展接口。整改时一并删除变量归档和 API 类型中的 `bucket_label_at_time`、`bucket_rule_version` 占位及要求它们存在的测试断言。历史已发布事实继续只读。

## 页面与个人记录

`/evening-report` 默认定位北京时间最近交易日。指定日期没有定稿时显示该日状态。区分等待输入、生成中、失败、未发布、定稿为空和筛选结果为空。历史行只显示报告日数据，打开共用股票弹窗查看的是当前行情。报告切换、刷新和后端 `evening_report` 更新均按交易日及归档标识刷新，不能串用其他日期的行。

- 表格显示名称／代码、题材、实际角色、价格与涨幅、辨识度、当日成交额、入选理由、低吸主因和反馈。详情展示排序依据、指标原值与待核验项。可按题材、角色、交易板块、低吸档位筛选，数值排序可恢复原顺序。入围但无获配股票的题材显示“已入围，0 只入选”。
- 星标独立于自选与盈亏。盈／亏互斥，同一按钮再点取消。按已登录账号及跟踪过程写当前状态，使用普通事务更新，失败恢复先前显示并提示重试。无需反馈事件日志、请求幂等表或乐观锁。个人标记不参与选股，不推断持仓。
- 观察历史按月查看推荐，可搜索代码、名称及筛选标记。反馈概览分别统计星标、自报盈亏、客观价格表现与样本数。连续 5 份相邻交易日的有效晚报均未推荐该股时结束跟踪过程。缺报打断缺席计数。恢复推荐后开启新过程，过程级回看从首次正式推荐起算。

后置的复盘差异展示只比较相邻交易日各自的定稿，列出新增、退出和入选理由变化。任一日缺报则显示无法比较。方向配额未启用。

推荐后的 D+1／3／5 表现由独立任务从已发布名单取证券与 D，直接读取评估时本地正式日 K、因子和标准日历。用同一复权基准计算目标收盘 / D 收盘 − 1。窗口内的有利／不利价格变化沿用既有回看口径，注明缺数覆盖。固定端点，不因停牌或缺价顺延。未到期、已到期待回看、不可评价和有效零收益分别显示。同一证券同日共用价格结果，个人标记按账号隔离。收益描述观察后的价格变化，不能替代自报盈亏。

启动评价的样本单位、冻结锚点、K+1…K+10 和期末 8% 条件见[离线研究规格](evening-report-dip-wave-spec.md#10-离线启动评价t5)。研究可以比较同题材同名额的简单基线，但不能用事后分类补造当时名单，缺历史分类的样本披露限制（T6）。离线评价按需读取本地报价、因子和交易日历。策略效果须另用前向样本验证。

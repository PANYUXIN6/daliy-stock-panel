# 龙头股晚报与站内观察页设计

状态：已完成本地实现；按2026-11-03用户要求调整为后续观察名单，页面仅显示最终入选股票。识别效果尚未验证，盈利不是本功能的验收目标。

本文确定每日筛选、角色延续、独立韧性、风险与报告用途，以及站内晚报的统计、归档和恢复。数值参数均为可执行、未校准的研究初值；规则可重复执行不等于有预测收益。已确认的八条约束直接替换旧规则，不构成对未讨论旧规则的自动背书。

遵循 [维护约定](../CONTRIBUTING.md)、[架构说明](ARCHITECTURE.md)、[盘后同步约定](postmarket-pipeline.md) 和 [扩展说明](secondary-development.md)。实际实现、验证与数据限制见 [实施与验收记录](evening-report-implementation.md)。

## 1 目标、范围与判断顺序

每天回答：哪些板块出现变化，谁已建立核心地位，谁可能属于后续扩散，压力表现是否受检，目前有哪些限制，与上一份报告相比改变了什么。

**观察目标与本次政策。** 晚报选出值得继续跟踪的股票，帮助后续复盘，不筛选或承诺“赚钱的股票”，也不要求展示日已经满足交易时机。本次保留数据校验、完整比较组、核心识别与延续规则；将市场未归类、弱势市场、压力事件尚未结束、位置过热改为明确提示，不再单独否决观察名单。其他资格、证据与风险条件仍按下文执行，不因提示政策变化将未知数据当作通过。本文“精选”及接口`selected`均指有限名额的观察名单，不表示收益优选。

已确定的产品范围：

- 股票仅限沪深主板、创业板普通A股，排除ST（包括*ST等风险警示）、科创板、北交所、B股、ETF及其他资产；资格按决策截点已知的标准化证券元数据判断。
- 只生成晚报，正式盘后数据就绪后归档并在站内页面展示。页面与侧栏名称为“每日晚报”，入口默认位于看板上方第一项。
- 暂不依赖隔夜新闻公告，不设计晨报、消息采集、外部发送或AI付费生成链路。采用结构化事实和固定摘要；不把消息未核验写成“无重大消息”。
- 股票可打开项目既有行情弹窗，并由用户主动快速加入自己的自选。报告不自动维护自选，不执行交易，也不推断用户持仓。

判断顺序为：**正式数据与时点证据 → 板块入口和轮次 → 完整同组地位评分 → 身份延续 → 独立韧性和当前风险 → 唯一主要报告标签 → 晚报统计与归档**。

底层事实分别保存，可以同时成立：

| 维度 | 结果示例 |
| --- | --- |
| 身份与生命周期 | 新晋、连板核心、趋势核心、分歧中的核心、地位失效 |
| 韧性证据与质量 | 尚未受检、样本有限、数据缺失；充分样本下良好／一般／较差 |
| 当前风险与限制 | 价格暂停、板块暂停新增确认、市场防守、位置过热、成交条件待确认 |
| 主要报告用途 | 早期变化观察、已确认核心跟踪、新增观察候选、等待位置确认、风险暂停、证据不足、地位失效 |

每只进入报告的股票只有一个主要用途，但标签不能覆盖或删除其他事实。例如“趋势核心身份＋等待位置确认＋韧性尚未受检”可以并存。没有压力样本仍可确认核心；高地位分不能抵消已知风险。

报告开头固定说明：**“本报告只提供观察与跟踪条件，不构成交易指令；新增观察候选不等于可买。范围为主板、创业板非ST股票，未核验隔夜新闻公告。”** 没有持仓信息，不称“持仓管理”，不输出卖出建议。日线先后走强仅证明时间顺序，不能证明盘中带动关系。

## 3 时间、范围、成员与时点证据

### 3.1 正式日期与截点

`t`为量化交易日，`T`为交易日历确认的下一交易日，`c_t`为本次计算采用的证据截点，均按北京时间。报告明确记录三者以及实际生成时间；长假查交易日历，不简单加减一天。下一交易日未知时仍可保存`t`事实，但观察日期标未知，不猜测。

正式输入包括同日正式股票行情、因子、指标、基准指数、本轮盘后取得的完整分类观察及成功完成的市场环境、阶段、主线计算。分类的取得时间与供应商业务生效时间分别记录；本轮观察成功不保证供应商当天更新，具体采用规则见第3.3节。零入榜是有效空结果；缺行情或任务失败不是零入榜。环境成功计算后合法返回unavailable／unknown，允许发布带证据限制的晚报，不把它当作通过市场门控。明确请求日期不可静默回退，旧报告只能带真实旧日期单独展示。

复用 [正式行情读取](../backend/app/tickflow/sector_review_reader.py)、[覆盖验收](../backend/app/services/daily_coverage.py) 与盘后发布规则。最新分区、全局最大日期或任意覆盖百分比不替代验收。非空 `quote_ts` 是快照证据，即使在收盘后也不能自行认定为正式日线。

全局正式行情或分类任务失败，不发布当日正式名单。全局就绪而局部窗口缺失，可发布其余可计算范围并披露缺口。必要证据不足与明确规则不成立分开；合取条件有明确false即为false，否则有unknown为unknown，否则true；析取条件有true即为true，否则有unknown为unknown，否则false。

### 3.2 单位与价格

| 项目 | 规则 |
| --- | --- |
| 收益、MA、ATR | 同一版本前复权价格；ATR与价格有限且为正 |
| 涨跌停、连板、一字板、制度 | 原始价及对应交易日实际规则，复用现有价格限制实现 |
| 成交量额 | 原始标准单位；成交额为人民币元，不复权、不解释为净流入 |
| 比例与分数 | 比例内部小数制，0.01表示1%；分数0—100 |
| 20日收益、MDD20 | `t−20…t`共21个收盘点与20个日收益 |
| H60 | 现有high_60d的60根有效日线最高收盘价，不是最高high |
| 近端连续性 | 最近21个市场交易日价格完整；缺日、停牌不能跳过凑样本 |
| 缺失 | 不填0、不造中性分、不拼旧日期，不以部分分项冒充完整分 |

至少60根预热记录可以跨更长日历范围，保存实际覆盖；正式性检查覆盖所有参与计算的历史价格、成交量额、ATR等递推前置状态，不能只验收当天。确认、压力、恢复和退出均按市场交易日。

若展示绝对计划价格，须转换到可交易原始价并记录依据；次日公司行动或因子未知时只给关系条件，不把昨日复权价直接写成次日委托价。

### 3.3 股票范围与完整比较组

研究范围 `U_scope(t)` 为截点已知的主板、创业板非ST普通A股。板块归属、交易板块和ST状态均需有来源、取得时间及版本；不只凭代码前缀猜资格。已证实退出范围的原跟踪对象仅在“历史身份退出事件”中说明，不留在当日候选和评分池；停牌等资格问题保留事件和原因。

基础池 `U(t)`：研究范围内正常交易、至少60根有效日线、近21个市场交易日价格完整、近20日成交额中位数≥1亿元。范围不明、资格未知与已知不达标分别计数。市场个股百分位 `P_U` 按当日实际涨跌幅制度分组；创业板20%制度与主板10%制度不直接竞争同一个市场收益百分位。无价格限制或特殊制度单独注明；市场同制度组样本少于20时不据其百分位正式晋级。

1亿元是典型日绝对成交规模的最低筛选初值，当前不按制度调整；同一人民币金额有一致的名义含义，不代表相同的盘口深度、价差、冲击成本或成交保证。不同制度覆盖率不同不能单独证明门槛不合理，须按第15.1.3节验证。

**成交额门槛覆盖。** 门槛前池`U_pre_amount(t)`只包含研究范围、正常交易、预热和近端价格完整等其余基础资格均已知满足的股票，不提前应用成交额门槛。按当日实际制度，在这一固定池内分别计数：`n_pass`为近20个市场交易日成交额窗口完整且中位数达标，`n_fail`为窗口完整但中位数不达标，`n_unknown`为必要成交额记录缺日、未就绪或不合法。窗口不完整时不能删日求中位数、补0或计为不通过。

```text
n_pre = n_pass + n_fail + n_unknown
n_decidable = n_pass + n_fail
门槛覆盖率 = n_pass / n_pre
可判定样本通过率 = n_pass / n_decidable
```

两项比率分别命名并附分子、分母，零分母不可计算；不能用筛选后的`U(t)`作门槛前分母，也不能把`n_unknown`计入可判定分母。已知停牌或其他基础资格不合格在门槛前池之外单列；其他基础资格未知也单列为上游资格缺口，不伪装为成交额不通过。停牌造成的窗口缺口不能补成零成交额后计为门槛筛除；先按上述基础资格口径归类，只有其余资格已知满足的对象才进入池内成交额三态统计。制度未知单列，不默认归入主板或创业板。

**分类观察的频率与采用规则。** 每个交易日随盘后流程重新取得概念和行业观察，采用本轮成功取得、截至`c_t`完整验收并留存的最新观察。现有分类预设仅提供股票及分类标签，没有可核验的供应商每日／T+1发布时间保证；记录观察取得时间、来源／版本、完整性，供应商提供的发布时间及业务生效日另存，未提供则标未知。不能把本地文件更新时间或取得日当作业务生效日。

本轮成功取得的最新已发布分类允许其业务截至日早于`t`，页面明确写“本轮观察、分类截至某日”；生效日未知则写“本轮观察，源生效日未知”。这表示按决策时可得分类配合当日价格计算，不声称已涵盖供应商尚未发布的当日变动。来源明确未来生效的成员变动不得提前应用；不能据此还原当前成员时，该观察不满足本次输入要求。取得内容与昨日相同可以是有效观察，不把它自动判为同步失败或供应商未更新。

本轮分类获取失败、不完整或仅一表成功时，不回退昨日本地文件生成当日正式名单，遵守现有盘后重试规则；页面保留带真实日期的上一份报告，显示“今日分类待就绪”。供应商内容的发布滞后与本次采集失败是两种情况，不能用前者为后者豁免。跨日取得的资料须按第13节迟到／修订及截点规则处理，不补造当时已经取得的观察。

分类完整性须来自本轮响应及其覆盖依据。现有[分类转换](../backend/app/services/ext_presets.py)不提供历史观察档案，[通用扩展表写入](../backend/app/services/ext_data.py)还会合并旧股票行；因此不能把合并后的文件、行数或mtime单独当作本轮完整快照或成员退出证据。实施时在同步／标准化边界保存并验收本轮成员观察与必要元数据，不要求改变通用扩展表的既有合并行为。

每个板块从该完整分类观察中，将属于`U(t)`的全部成员确定为 `M_s(t)`，至少6只。`G_s(t)=M_s(t)`为完整地位比较组，不先筛候选。成员进入集合依据当前已知资格，不称`t−20`形成日资格；筛除数、数据未知数和流动性不达标数分别披露。已入集合后缺少某类评分必要分项，该类完整排名不可计算，不能再删除缺分成员重新排名。

当前正式规则的板块内百分位 `P_s` 使用完整 `G_s(t)` 跨制度混排。板块内某制度子组即使不足20只，仍参与混排，不据此剔除成员或缩小比较组；这不豁免 `P_U` 自身的市场同制度组样本要求。报告披露每个板块各实际涨跌幅制度的成员数，制度未知单列，不能归入默认制度。第15.1节的收益百分位分层仅为独立研究方案，不替代本节正式规则。

**当前成员同组基准**：先按上述基础资格建立`U(t)`和`M_s(t)`，再计算收益与评分。本次计算在5日、20日收益及压力窗口内使用同一`M_s(t)`；先计算每天成员等权收益，再逐日复利。板块比较使用完整集合；个股`i`的基准剔除自身，至少保留5只其他成员。组确定后，必要行情缺失时相应聚合不可计算，不再删除缺失成员重归一、不用零收益代停牌；缺少评分分项仍使相应完整排名不可计算。

**部分成员停牌的决定：采用建组前排除的方案2。** 分类成员关系与本次合格比较组分开保存。确认当日全天停牌的股票不进入`U(t)`，已复牌但最近21个市场交易日仍包含确认停牌日的股票也暂不进入；停牌行或沿用停牌前价格的记录不能充当有效收盘点。统一据此建立本次完整`M_s(t)=G_s(t)`，所有成员的基准、百分位和排名使用同一组。排除在评分前由固定资格规则决定，不是看到某股缺分、低分或排名结果后再删股，因此不属于禁止的“删缺失成员凑出完整排名”。

这不是逐个历史交易日删掉不同停牌股后重新等权：本次窗口内成员固定，下一报告日才按新资格重建。复牌股票须等最近21个市场交易日具有真实有效的完整价格并满足其余基础资格后回组，不跳过停牌日拼接21根K线，也不为保留它而改变基准分母。它仍是“当前合格成员的历史比较”，不代表包含停牌股的完整板块投资组合收益。

停牌须有对应交易日且截至`c_t`已取得的明确证据：沿用正式日线覆盖的停牌行判据、数据源显式名单或独立状态源的全天覆盖核验，保存来源、适用日期和取得时间。行情缺行、接口失败、空值或状态不明本身都不是停牌证据；盘中临停或半日停牌也不按全天停牌排除，仍须有效正式日线。资格未知按前述上游缺口单列，不能计为已知停牌；本次组确定后的缺项仍遵守完整性规则。晚报复用盘后证据，不自行绕过数据源与标准化边界另抓行情。

排除后至少6只、剔除自身后至少5只的门槛不降低。例如其他条件均完整时，7只中1只停牌可用剩余6只继续计算；6只中1只停牌则仅剩5只，板块基准与完整排名标“停牌后合格成员不足”，不能改用4只同伴或扩大到其他板块。既有身份保留在独立跟踪记录中，不因退出评分组就消失；样本不足引起的当日维持缺口按第7.1节待核验，已知独立失效条件仍执行。方案不承诺消除所有中断。

每板块披露范围内分类成员数、当日确认停牌排除数、已复牌但窗口未恢复数、其他资格排除及未知数、最终`|M_s(t)|`和可计算状态；保留逐股原因，原因可并存时不直接相加成互斥总数。文案分别使用“当日停牌排除N只”“复牌后窗口未恢复N只”，不能把两者统称当日停牌。成员数和身份跟踪连续性的实测审计见第15.1.4节。

它回答“今天已知的这组成员过去表现怎样”，不是“板块过去20日真实收益”或“固定形成日成员收益”。每日集合可以变化，题材轮次不把成员冻结数月。该口径为本策略单独实现／参数化复用，不改变既有板块复盘契约。

本策略不额外设置成员冷静期：新看到的成员只要当日证据完整即可参加基准和同组评分，核心仍需普通持续确认。首次启动看到且过去归属未知的成员标“首次观测、此前归属未知”；只有相邻完整快照明确前无后有才称“确认新增”。冷启动、快照缺日后重现不冒称刚加入。

### 3.4 实时发布与研究重放分离

- **实时发布**只用`c_t`前已取得并保存的输入。成员、资格、分数、轮次和先后关系均留存证据，不用后来补齐资料改写原发布。不存在早期记录时初始化，不凭当前分类回填历史核心、补涨或Top5次数。
- **严格研究重放**可用供应商或系统自身的可验证时点记录，逐日截断。验证须覆盖成员进入／退出、分类新增／消失、历史修订、资格变化以及当时可见版本；供应商接口声明本身不够，需样本核验。研究结果单独存储和标注，不冒称当时实际发布、不拼入实时业绩。
- 只有当前快照的回看可做特征探索，标`current_snapshot_backcast`，不生成具有时点效力的历史核心、补涨或轮次结论，也不据此证明策略有效。

每份结果记录分类来源／层级、成员版本、取得时间、前后增减和完整性。成员与排名同时变化不证明因果；没有固定其他输入的对照计算，只写“比较口径发生变化，排名变化原因尚未分离”。可解释时另附对照条件和结果，不能强制归因。

## 4 板块入口、轮次与主归属

### 4.1 独立入口与百分位分母

概念和行业分别计算，行业统一二级，一级仅展示大方向。市场基准沿用板块复盘默认上证指数，同次计算全链路一致，不逐股挑选容易跑赢的指数。概念排除交易通道、地域、指数成分等非产业标签，沿用已核验的分类过滤元数据并保存配置；不让AI决定名单。

候选、个股百分位、当前成员同组基准以及本策略涨停生态榜均限定主板、创业板非ST范围。本策略涨停榜复用现有算法、至少3只涨停参评，保存独立scope及版本，不覆盖全A主线；全A市场情绪仅是显式标注的背景。

定义板块5日、20日相对市场净值收益为`X_s,5、X_s,20`。趋势百分位在**同来源、同层级、同范围、通过既定元数据过滤且具备基础成员资格的完整可计算板块**中计算，不能先截Top30或先筛出正收益候选。

`P_sector`使用第5节升序平均排名公式，并列不任意打破以凑入选比例。样本数`N≥20`才产生正式趋势入口，阈值为`P_sector(X_s,20)≥90`；不足20标“百分位样本不足”，不强行排名。全部并列得50，不会全部通过90分门槛。入口阈值与20个最小样本均为未校准初值。

| 入口 | 当日规则 |
| --- | --- |
| 情绪入口 `E_s` | 本策略当日涨停生态Top5，或截至当日过去5个交易日至少2次Top5；历史只用当时记录，已知足够2次可成立，否则缺日为未知 |
| 趋势入口 `T_s` | `R_s,20>0 AND X_s,5>0 AND X_s,20>0 AND P_sector≥90`，且百分位样本充分 |
| 轮次进入条件 `B_s` | `(E_s OR T_s) AND X_s,5>0 AND X_s,20>0` |

涨停生态入口无需趋势百分位；趋势入口无需凑足涨停家数。进入轮次共同要求中期超额为正，避免仅靠热度在同一中期失效事实下立刻退出；代价是早期反转先观察。

分别披露概念与二级行业：应覆盖板块数、可计算数、已知基础不合格数、缺数据数、入选数及各入口数。应覆盖集合由当日完整分类目录、范围和元数据过滤确定，数据缺失不能缩小分母；明确少于6只范围成员等结构性不适用项单列排除，资格不明仍计入缺口。

`覆盖率=可计算板块数/应覆盖板块数`，`入选率=入口成立板块数/对应入口可计算板块数`，零分母为不可计算。趋势与涨停生态的可计算定义不同，分别给分母，不能把“未达到3只涨停”当采集失败，也不能用Top30条数冒充全量覆盖。

### 4.2 轮次状态与计数

轮次是本策略的状态定义，不等于真实行情起点。全链路使用三态条件：true累计、false清零、unknown打断连续计数；未知不跨缺日拼接。

| 当前状态／条件 | 处理 |
| --- | --- |
| 无有效轮次 | `B_s`连续2个交易日true，第二日确认；第一日只记试探 |
| 已有轮次且`X_s,5>0 AND X_s,20>0` | 活跃；掉出Top5或90分位不单独结束或暂停 |
| 上述活跃条件明确false | 暂停观察，保留历史和身份，停止新增正式确认 |
| 活跃条件unknown | 待核验，停止新增正式确认；保存未知原因 |
| 暂停后活跃条件恢复true | 同轮恢复活跃，无额外板块冷静期；个股仍按自身维持／恢复规则检查 |
| 连续2个市场交易日的`X_s,20≤0`均为true；unknown打断连续计数，不跨缺日拼接 | 结束轮次，无论是否暂停或仍有涨停热度 |

新轮确认时退出计数归零，从次日起判断。暂停期间继续检查中期失效：成立累计、明确不成立清零、必要数据未知打断；短期暂停本身不算一次中期失效。结束优先于同日重开，新轮须结束之后重新连续2日满足入口。2日确认／结束为未校准初值，不声称最优。

板块暂停不能冻结个股已成立的失效条件；ST、退市、明确退出归属和个股维持失败仍分别处理。恢复不复活已失效身份。轮次与个股资格可以并行积累，个股正式确认日必须处于已确认且活跃轮次，不能机械等待板块确认后再开始积累全部日证据。

因停牌排除后成员不足或基准输入缺失而不能计算`X_s`时，相应条件为unknown，已有轮次待核验、停止新增正式确认，不把样本不足当作`X_s,20≤0`或自动结束轮次。成员恢复充分后按当日证据继续原轮判断，不跨待核验日拼接连续计数。

保存轮次ID、试探／确认／暂停／恢复／结束日期及触发依据。首次观测左边界未知时注明“观察起点截断”，不声称发现了真实起涨日。

### 4.3 主归属

股票分别允许一个主要概念归属和一个二级行业归属，单独解释、报告按股票去重。初次从有可验证成员关系且已确认活跃轮次的板块中，按过去5日Top5次数降序、当日主线名次升序（未入榜排后）、板块20日超额降序、板块标识稳定排序选择；只用板块证据，不挑个股最高分板块。

主归属建立后，在轮次有效且成员关系成立期间保持，短期暂停不自动换板块。轮次结束或明确退出成员关系才重选；缺失不等于退出，不借未知切到次优板块。新归属重新确认身份，不拼接旧板块达标日。早期观察使用同样板块排序确定“观察关联”，只在该关联连续日上累计候选证据，不提前冒称正式主归属。

这里的成员关系指分类归属，不是当日是否进入`M_s(t)`。停牌及复牌后窗口未恢复导致暂离评分组，不构成明确退出归属，也不触发换板块或新身份区间。

其他板块只附关联证据。主概念不可计算不妨碍证据独立完整的行业核心，但不能将其包装成概念龙头，也不能拼两个归属的最佳分项。

## 5 地位分与完整评分范围

### 5.1 归一化

```text
clip(x,a,b) = min(max(x,a),b)
N(x;a,b) = 100 × clip((x−a)/(b−a),0,1)，b>a
P_G(x) = 100 × (组内升序平均排名(x)−1)/(组内有效样本数−1)
```

并列用平均排名，全部并列或只有一个样本时为50，无有效样本不可计算。数学定义不豁免各自的正式样本要求：`P_U`的市场同制度组至少20只；`P_s`使用至少6只的完整板块组，个股基准剔除自身后至少5只；板块间趋势百分位`P_sector`至少20个可计算板块。正式规则不另设板块内制度子组人数门槛。正式比较组所需分项必须完整，不能靠删掉缺分成员得到“完整排名”。排序使用未四舍五入值。

`P_U`中的`U`为完整基础池中当日实际涨跌幅制度相同的市场组；`P_s`中的`s`为完整 `G_s(t)`，收益与成交额百分位均跨制度混排，包含板块内人数较少的制度子组。定义：

```text
r_i,d = C_i,d/C_i,d−1 − 1
R_i,n = C_i,t/C_i,t−n − 1
R_s\i,n = product(1 + 剔除本股后的板块等权日收益) − 1
X_i,n = (1+R_i,n)/(1+R_s\i,n) − 1
```

板块相对市场收益也使用相对净值公式，不把日超额简单相加。不同制度、不同板块的百分位不代表相同绝对强度，报告同步保留真实收益与超额。

`X_s,20(t)`是按`M_s(t)`重新计算的滚动20日相对收益，`X_s,5`同理。跨日变化同时受价格、窗口滚动、成员／资格变化及输入版本影响，不是同一固定篮子的收益增量，也不能将每日`X_s,20`串成实际投资组合净值。`P_sector`是当日截面比较，其变化还可能来自比较板块及分母变化。轮次连续条件表示连续日期各自当前组的条件成立或不成立，不保证同一篮子连续满足；成员变化可能影响进入、暂停和结束。正式规则仍采用动态当前组，不另加冻结成员或冷静期；报告同时披露前后成员、排除原因及比较分母，未经固定其他输入的对照，不把变号或排名变化全部归因于板块行情转强／转弱。

板块内混排未消除制度与波动差异，可能影响收益分布上尾的入选，是否形成系统性偏向须按第15.1节验证，不能由制度差异直接断言。`L`与核心身份描述行情相对地位，不据此证明主营业务领导力。

### 5.2 分项

| 分项 | 公式 | 含义 |
| --- | --- | --- |
| 空间 `S` | `P_U(R20)` | 同制度20日强度 |
| 辨识度 `I` | `0.6N(20日涨停次数;0,6)+0.4N(20日最高连板;0,5)` | 涨停重复度及高度 |
| 领涨 `L` | `0.5P_s(X20)+0.3P_s(X5)+0.2N(C/H60;0.85,1)` | 跨制度的板块行情相对地位与接近收盘新高 |
| 近期强度 `J` | `P_U(R5)` | 同制度5日强度 |
| 成交关注度 `V` | `P_s(近5日平均成交额)` | 板块内成交关注，不解释为净流入或市值中军 |
| 加速 `A` | `N(a;0.25,0.65)` | 正收益集中到近期的程度 |

20日最高连板直接取窗口内现有连板字段最大值，不在窗口边界截断真实连板高度。加速比为：

```text
g_d = ln(C_d/C_d−1)
a = sum(max(g_d,0),最近5日) / sum(max(g_d,0),最近20日)
```

价格完整且分母为零时`a=0`；行情缺失则不可计算。加速只证明近期贡献集中，不能单独证明低位、补涨或因果。

### 5.3 两类地位分

对所有可计算板块，先批量计算完整合格组的特征与排名，供早期观察和后续身份判断使用；正式身份再按第4节归属与轮次条件确定。趋势核心不经过涨停、12%或20%大涨、新高等预筛。上述条件仅作短线发现标签；核心持续跟踪到明确失效，不在五天后自动移除。

```text
H_b = (0.25S + 0.30I + 0.25L) / 0.80
H_t = (0.35S + 0.30L + 0.10V) / 0.75
H_e = (0.35J + 0.25A + 0.20L) / 0.80
```

`H_b`为连板地位、`H_t`为趋势地位、`H_e`为近期加速质量。三者均固定排除韧性，对所有股票保持相同权重；缺韧性时也不再临时归一。旧综合分75分与新地位分75分不等价，以下门槛是新规则初值。

| 类型 | 当日进入资格 |
| --- | --- |
| 连板核心 | `H_b≥75、I≥50、L≥70`；最近5日至少出现一次真实连板≥2；对应地位分在板块前2 |
| 趋势核心 | `H_t≥75、L≥70`；对应地位分在板块前2 |

个股共同要求为`R20>0、X20>0、C≥MA20`及基础资格、必要数据完整；满足表中条件可记录当日新晋候选。正式确认另要求主归属已确定、本轮已确认且当日活跃，以及第7节持续条件。韧性未受检不阻断身份；风险另决定观察限制。

同类型排名对完整合格组按对应`H`、`L`、`X20`、股票代码依次排序；进入前2与第7节维持前3使用同一完整板块组统一排名，不按制度分别分配名额。不以韧性做排序决胜，避免无压力样本再度被间接排除。连板与趋势分不取最大值合成全市场龙头分。

## 6 独立韧性评价

### 6.1 压力与波动尺度

```text
v_d = ATR14_d/C_d，ATR14_d与C_d有限且为正；v不裁剪
```

ATR使用与收益相同的前复权序列；v是未经1%—5%上下限裁剪的原始有效ATR比例。ATR缺失或不合法时不可计算，不能用下限填缺失。下式z自身的[-2,2]极值裁剪另有含义，不改变v。压力日满足“剔除本股后的板块日收益≤−1%”或“市场基准日收益≤−1%”。最近20个收益日均须能判断；未知日不当作非压力日。

### 6.2 分歧抗跌

```text
D = 最近20个收益日中的压力日集合
z_d = clip((r_i,d−r_s\i,d)/v_i,d−1,−2,2)
win_ratio = count(r_i,d>r_s\i,d,d∈D)/count(D)
D_score = 0.6N(mean(z_d);−1,1) + 0.4×100×win_ratio
```

相等不计跑赢；使用前一日ATR。板块跌3%、股票跌1%属于相对抗跌，不等于上涨或主动带动。市场下跌而板块上涨时，仍比较是否跑赢自身板块。

### 6.3 历史回撤控制

```text
MDD20 = max(1−C_w/C_u)，t−20≤u≤w≤t
C_score = 100 × [1−clip(MDD20/(6×v_t−20),0,1)]
```

包含`u=w`，最大回撤至少为0。固定窗口起点波动，避免暴跌后波动上升使分数反而变好。它衡量历史收盘回撤，不是盘中最大损失，也不代表当前尚未修复的跌幅。

### 6.4 不重复的三日承接或修复

在本次当前成员同组基准下，按时间顺序扫描压力日。首个压力日`d`开启事件，观察`d…d+3`共四个交易日，窗口内不再开启新事件；`d+4`起下一次压力才能新开。窗口不因连续压力无限延长；各窗不重叠，但不宣称统计上相互独立。

每天从本次20个收益日的首日`t−19`开始扫描，保留各观察块的起止日。这是单次评估窗口内的局部去重，首端可能截断更早发生的冲击；“事件”仅指本次固定观察块，不代表跨报告永久一致的市场事件身份。跨日窗口或成员变化时，划分和数量可能变化，不能把新出现的观察块自动写成又发生了一次独立冲击。

只对`d+3≤t`的成熟事件计算：

```text
m_d = min(C_d,C_d+1,C_d+2,C_d+3)
loss_d = (C_d−1−m_d)/C_d−1
若 loss_d≤0.25×v_d−1：F_d=100，标记基本守住
否则：F_d=100×clip((C_d+3−m_d)/(C_d−1−m_d),0,1)
F_score = mean(成熟完整事件的F_d)
```

修复分支分母必然为正。压力前100元、窗口最低收盘95元、末日98元，则`F_d=60`。始终守住附近得到的是承接证据，不写成一次下跌修复。

未成熟事件显示“压力进行中”，不使用未来价格，不判修复失败，也不让旧成熟事件的好成绩掩盖当前冲击。必要价格缺失不以更晚记录替代。另记录压力日数、成熟事件数、当前事件及连续压力天数。

### 6.5 证据状态与质量

```text
R = 0.45D_score + 0.30C_score + 0.25F_score
```

完整`R`要求至少3个压力日、2个成熟完整事件及其他必要输入完整。不足时可显示已算分项，但`R=null`，不补中性分、不重新分配权重。分开保存样本状态与质量，允许“样本有限＋已知历史损伤严重”并存。

| 证据状态 | 规则 |
| --- | --- |
| 尚未受检 | 必要输入完整、没有压力日；历史回撤仍可单列 |
| 样本有限 | 有压力但不足3日或2个成熟事件 |
| 数据缺失 | 必要输入未知，不能断言完整压力日数或完整R |
| 样本充分 | R全部样本与输入满足要求 |

充分样本的质量：`R≥70`且各分项≥40为良好；否则`R≥60`且各项≥30为一般；其余较差。未充分时不评完整质量，但任何已计算分项<30须标局部弱证据。`D=100、C=0、F=100`即使R=70也不满足良好，须披露历史损伤。

无足够样本固定说明“近20日无足够压力样本，抗跌与修复能力尚未验证”。无压力不是数据缺失；缺R不阻止完整的核心身份跟踪。充分样本的整体质量较差、局部较差证据仍产生第9节入选限制，不能由高地位分覆盖，但不自动等于当前价格风险暂停。压力进行中单独提示“压力观察尚未结束”，不阻止其他条件完整通过的股票入选，也不提前断言已承接或修复。例如D=C=F=55时，R=55属于整体较差，即使各分项都高于30也限制精选。

## 7 核心生命周期与变化解释

身份按“股票、主归属板块、轮次、类型、规则版本”分别维护。

每次正式确认开启一段身份区间，以确认日`c`为起点，明确身份失效日`e`为排他终点，即`[c,e)`；未观察到失效时`e=null`，另存证据观测截至日，不把未来失效日写入当时报告。失效后回归开启新区间，不沿用旧区间的确认日。身份待核验不自动结束区间，也不能仅凭尚无失效事件证明该日有效。

### 7.1 进入、维持、失效

- 第5节分数、排名和股票资格构成“个股进入条件”；板块试探期间即可积累同一观察关联的日证据。首日满足记新晋候选；正式确认须当日仍满足、最近3个连续市场交易日含当日至少2日满足同类型条件，且当日主归属明确、轮次已确认且活跃。
- 该3日窗口必须有完整判定记录；unknown日不算false，也不能跨过缺日凑2次。规则、归属、轮次变化后重新累计。板块暂停期间不新增正式确认，但保存日证据，恢复后检查最近窗口。
- 已确认核心维持条件：`H≥65、L≥60、R20>0、X20>0、C≥MA20`，对应排名前3。连板核心不要求每天继续封板；断板单列。
- 维持true继续；连续第1、2次false为分歧中的核心；连续3次false为地位失效。分歧后连续2日true才恢复延续，恢复首日仍观察。unknown打断失败和恢复连续计数，身份待核验，不当成false或延续。
- 轮次结束、明确退出归属、ST、退市或退出股票范围，立即使当前身份失效。确认停牌触发交易暂停；无独立已知失败／失效事实时，既有身份待核验。复牌后因该停牌导致近21日窗口尚未恢复，同样待核验，不因这一缺口累计维持失败。两种待核验状态均保留原身份区间和历史事实，但不证明当日身份有效，不能作为第8.1节连续有效核心参照。
- 已知流动性等可独立判定的基础资格不达标明确计为一次维持失败，即使因此没有当日分数；必要数据未知则待核验。上条停牌及其遗留窗口缺口不按资格失败计数，不能补零成交额后制造流动性失败。其他独立可判定的维持false或立即失效事实仍执行，不被停牌、板块暂停或待核验状态冻结。
- 其他成员停牌后剩余组满足第3.3节人数与完整性时，正常评估本股维持，不连带暂停本股交易。若剩余组不足且没有独立false，本股维持为unknown、打断失败与恢复连续计数，保留身份跟踪记录；不把暂时无分数改成地位失效。数据恢复后按原维持／分歧恢复和第9.1节风险解除规则继续，不补写缺日的有效性、不额外追认连续确认；期间已明确失效的身份仍须重新进入和确认。

同一板块同次试探转为正式轮次、同一观察关联成为正式主归属，是同一条证据链的状态转正，不清空已保存的试探期记录。只有实际换板块、旧轮结束后新开轮或规则变化才重新累计；不得把其他板块或失败试探的记录带入。

确认所需记录完整但成立次数未达标时，确认条件为false，保持当日已成立的候选事实；必要日记录缺失时为unknown，注明确认待核验，不把缺记录算作已知未达标。两者均不追认正式确认，主要用途按第9.4—9.5节当前适用判断链处理。已失效身份即使风险解除也须重新进入和确认；历史修订不改写原发布，按第13节单独记录。

### 7.2 换位、回归与启动先后

- 新股票确认而旧核心仍满足维持条件时称“新核心加入”，不能仅凭排序变化称替代。
- 同一板块、轮次、类型中，旧核心明确失效且新核心已确认，才能称“核心换位”；记录双方日期与原因。
- 曾失效的核心再次满足完整进入和持续确认，称“回归”；新轮次重新确认则称“新一轮确认”。本设计不凭回归标签宣称二波。
- 每个轮次跟踪合格股票首次满足`R5≥12%且a≥0.45`的日期`k`，作为日线启动证据；独立于其是否随后被判补涨。该触发在轮次试探日及以后扫描，可晚于实际起涨，报告称“规则首次触发日”。
- 核心可能未触发短线加速规则；用于补涨先后关系的`c`是所引用身份区间的确认日，不能用本轮更早但已失效区间的确认日，也不能伪造一个启动日。

保存进入、持续、分歧、暂停、失效和回归事件及当日原始证据。历史记录不会因未上精选摘要而删除。首次看到股票已满足启动阈值而左侧缺记录时，只记“最早已观测触发”，不能冒充本轮首次触发；涉及先后关系的补涨判定须等待可验证记录。

## 8 补涨、加速与早期观察

### 8.1 补涨的条件与三态结果

补涨是时序与相对位置分类，不由加速分单独决定。必要条件：

1. 当前主归属处于同一已确认且活跃轮次。
2. 至少存在本轮另一只股票的一段固定核心类型的已确认身份，其确认日`c`严格早于本股可验证首次启动日`k`，且从`k−1`至当前`t`的每个市场交易日均有证据证明该段身份仍有效；整段使用同一主归属板块、轮次、类型和规则版本，不仅检查两个端点。
3. `k−1`本股20日收益不高于当日同板块完整合格组跨制度混排的60%分位值。分位值采用升序线性插值`h=(n−1)×0.6`，取相邻序号值插值；只读当时成员、分组和已知结果，不能用今天分位替代。
4. 当前`R5≥12%、a≥0.45、H_e≥70、L≥60、X5>0、C≥MA20`，且本股尚无已确认核心身份。
5. 当前距`k`不超过5个市场交易日（`k`为0）。超期保留启动记录，不在同轮重置k续贴补涨标签。

条件2按独立身份区间检查连续性。分歧中的核心（连续第1、2次维持false）仍有有效身份，不打断参照；连续3次false或第7.1节其他明确失效事件才结束该区间。没有失效事件还须有逐日有效性证据，身份待核验或记录缺日不能当作持续有效。区间内已知失效为该条参照不成立；无已知不满足项但必要连续性证据缺失为unknown。

不锁定唯一先行股票。对本轮其他股票的各类型身份区间分别判定，再按第3.1节三态OR汇总：任一完整参照成立即满足条件2；没有成立项但有待核验参照或参照记录覆盖缺口为unknown；完整记录证明所有参照均不满足才为false。不能将不同股票、不同类型或失效前后的两段身份拼接为一条连续参照。条件2的结果再与其余补涨条件按AND合并。

**停牌不豁免连续有效性证据。** 参照本人停牌或复牌窗口未恢复而身份待核验时，该日不能视为有效身份日；无独立已知不满足项时，该条参照为unknown。另一条完整参照仍可使条件2成立；若无成立参照且其余补涨条件都成立，当前补涨为证据不足，保留历史补涨记录及独立成立的加速／核心事实，不删除此前信号，也不沿用此前资格冒充今天仍成立。

例如参照在`k+2`停牌，即使`k+3`复牌，该缺口仍位于`[k−1,t]`中，同一参照不能靠复牌补回该次启动的连续性；其他完整参照仍可支持。超过`k+5`后条件5明确false，整体补涨不成立，不能一直写unknown。原发布的停牌缺口不由后来资料反向补齐。这一选择可能减少可判定补涨，减少程度尚未实测，按第15.1.4节保留全部机会与多参照情况评估后再决定是否另改规则。

本次判定保存参与核验的参照清单及各自真值、失败／未知原因；所有成立参照均为本次采用依据，不另设固定唯一参照。报告明细与归档记录参照股票、类型、板块、轮次、规则版本、确认日`c`、区间起点、截至截点已知的失效终点`e`及证据观测截至日。未结束区间`e=null`，不能用当前`t`伪装已结束日期；同时关联本股`k`和`k−1…t`的连续性证据。

参照回归后的新确认日只可支持满足新`c<k`的后续启动，不能用于回归之前或同日已经发生的启动，也不能反向补齐旧区间缺失证据。参照失效、回归或更换均不重置本股`k`；后来失效只影响之后的当前补涨资格，不否定此前已成立的原发布，修订仍按第13节隔离。

启动前60%分位在当前正式规则和第15.1节方案A中均保持完整板块混排，不随`L`的实验分层改变；未来若要分层，须单独决定并登记比较口径。方案A仍须重算`L/H_e`及先行核心等依赖，因此60%分位口径不变不代表补涨结果不变。

| 判定结果 | 条件 | 报告文案 |
| --- | --- | --- |
| 条件成立 | 全部必要条件已知且满足 | 补涨试探／补涨持续确认，仍非“补涨龙” |
| 条件不成立 | 至少一项已知不满足，其他未知不能抵消 | 当前不符合补涨条件 |
| 证据不足 | 无已知不满足项，但必要证据缺失 | 当前无法判定是否补涨 |

同时保存全部原因，例如：核心先行记录不可用、启动前位置不可还原、记录完整但当时无合适先行核心、已知同步启动、窗口超期。原因不是互斥判定结果。没采到核心记录与完整记录证实没有核心必须分开。

当日成立且最近3个市场交易日判定完整、至少2日成立，记补涨持续确认；首日为试探。若同时达到核心首日资格，主要候选角色采用新晋核心，保留补涨来源事实。确认核心后停止当前补涨资格，仍保留历史来源。

`k<c`是更早触发，`k=c`是同期，`k>c`仅提供后续扩散的可能，不能省略其他条件。左边界未知可能使当前无法判定；上线初期可持续无法形成补涨标签，不承诺固定几天／几周后一定可用，也不影响独立成立的趋势核心。

### 8.2 早期变化与普通股票

早期观察采用明确初值：当前基础资格和可计算关联板块完整，且满足以下任一：

- `H_t≥65、L≥60、X5>0`，同一观察关联中相较上一交易日`H_t`和`L`均上升；
- `R5≥12%、a≥0.45、X5>0`形成加速事实，但尚无正式候选／核心资格。

只描述已发生的强弱、排名或成交事实，不承诺提前发现未来龙头，不进入新增候选精选。没有满足任何报告条件的普通股票保留计算或排除原因，不强行塞入七类标签；弱于核心也不自动叫跟风。缺补涨证据时可以独立写“加速事实成立、补涨无法判定”。

## 9 当前风险、观察限制与七类用途

### 9.1 当前风险独立于韧性

历史最大回撤`MDD20`、`C_score`只作历史损伤证据。另披露当前回撤：

```text
p = t−20…t内最近一次最高收盘所在日
DD_now = 1 − C_t/C_p
```

`DD_now`给绝对比例；本设计不采用“6v当前回撤单项暂停”。当前风险按以下规则明确取OR，各项返回true／false／unknown：

```text
limit_down = 当日收盘按原始价及当日实际规则确认跌停
structure_break = MA20_t − C_t ≥ 2 × ATR14_t
abnormal_d = (r_d ≤ −2 × v_d−1) AND (r_d ≤ −0.05)
abnormal_pair = abnormal_t AND abnormal_t−1
qualification_pause = 截点已知停牌、ST、退市或其他明确退出研究范围的资格状态
risk_now = limit_down OR structure_break OR abnormal_pair OR qualification_pause
```

`structure_break`判断收盘价相对MA20的向下偏离达到多少个ATR，不要求当天大跌；连续缓慢下移后当天持平或小幅反弹仍可命中。价格、MA和ATR同时乘同一正数时结果不变，低名义股价本身不是更易触发的原因。需要研究的是有效`ATR/C`很小时，2ATR对应的相对均线偏离也很小，属于可能敏感而非已经证明误报。正式规则保留当前公式，不增加固定金额或当日跌幅下限；第15.1.2节的最小相对偏离`ε`仅用于独立研究对照。

该分支的价格、MA、ATR及其历史输入须通过第3.2节同版本、有限正值、预热与完整性检查；ATR为零、非有限、不合法或必要预热／输入不足时，该分支不可计算，记录ATR不可用原因，不以极小正数填补。合法且有充分输入支持的极小正ATR仍按原值计算，不能仅凭“接近0”改成不可用或另设隐含下限。若实际价格精度、复权或计算证据显示ATR不可靠，须明确质量问题及判据，独立于`ε`实验处理；未定义可用性阈值前，不声称已排除所有极小ATR。某分支不可计算仍遵守风险OR规则，不能抵消其他已知风险命中。

异常下跌同时要求波动倍数和最小绝对跌幅，两天各自满足；2倍、5%均为未校准初值。价格与ATR同一前复权口径，跌停使用原始价；特殊制度按真实限制，不能硬套10%／20%。任一分支true立即暂停，其他unknown不能抵消；没有true但必要风险分支unknown，则`risk_now=unknown`，独立标注“当前风险证据不足／尚未通过风险核验”。这不单独触发第9.4节主要标签“证据不足”，也不等于风险检查通过或允许进入精选。

风险暂停独立保存：触发消失首日仍暂停。解除价格暂停须连续2个交易日全部价格分支明确false，且`C≥MA20、X5>0`；unknown打断恢复计数。已有暂停尚未满足全部解除条件时，主要标签仍为风险暂停，不能因当日仅剩unknown就改为核心跟踪或候选。交易资格暂停还须明确恢复证据。ST／退市等已导致身份失效的，解除暂停不复活身份。

股价已修复而旧MDD仍大时，不因旧回撤单独维持当前暂停。历史较差分项仍披露并产生观察限制，但不能把历史损伤改写成当日风险命中。

### 9.2 市场、板块与韧性限制

主要报告用途与限制分开保存；已确认核心即使处于防守环境仍可供跟踪，不能因此表述为可参与。

| 背景 | 限制与展示 |
| --- | --- |
| 短线启动、主升 | 展示已确认核心和候选；启动阶段补涨保留试探说明 |
| 短线高潮 | 标市场过热、等待后续条件，不以高分写追入指令 |
| 短线修复 | 标修复观察；不是已经恢复完成的保证 |
| 短线退潮、冰点 | 保留短线退潮／冰点提示，不因市场防守单独阻止核心或候选进入观察名单 |
| state偏弱／弱势，或原始晋级率与封板率同时偏低 | 明示弱势背景及具体依据，不单独否决观察名单 |
| state=unavailable | 标“市场状态不可用”，说明综合状态无法计算；保留自身判断完整的核心／候选跟踪，不进入精选，不当中性 |
| phase=unknown | 标“阶段未知”，说明阶段核心输入不足；保留自身判断完整的核心／候选跟踪，不进入精选，不当修复 |
| phase=unclassified，原分类原因是未命中规则 | 标“阶段未归类：当前未命中阶段规则”；不单独阻止观察名单入选，不冒称已有阶段结论 |
| phase=unclassified，原分类原因是候选待确认 | 标“阶段候选待确认”，附已知候选阶段和确认进度；不单独阻止观察名单入选，不提前确认候选阶段 |
| 板块暂停／待核验 | 停止新增正式确认；既有身份继续独立维持／失效判断 |
| 核心维持不足、韧性整体或局部较差 | 明示分歧或韧性限制，仍限制入选，不删除已确认身份 |
| 当前压力块未成熟，其他必要证据完整 | 明示压力观察尚未结束，不单独限制入选，不把未成熟当作修复成功或失败 |

上述理由分别保存，可同时出现，不合并成笼统的“市场背景无法判断”。`unclassified`既不等于防守／高潮，也不等于核心输入缺失；本版将其作为背景提示。弱势防守项同样只作提示，高潮及必要输入缺失仍独立限制入选，不能只看`unclassified`就放行全部市场检查，也不因此把主要标签改为证据不足。“未命中规则”不声称所有输入与历史窗口都完整，仍披露已知局部缺口。

`classify_phase_series`在原分类器的同一次因果计算中输出最终`phase`，同时保存`phase_reason`（未命中规则／候选待确认）、待确认候选阶段及连续确认计数；沿既有环境结果传给晚报，不能在晚报或前端复制分类逻辑或仅凭最终`phase`猜测原因。已有有效阶段切换时也可能存在待确认候选，此时按原实现保留旧阶段，不为展示候选而强改为`unclassified`。新增说明字段不改变既有阶段枚举和确认规则。

历史归档只有`phase=unclassified`而没有当时原因时，标“阶段未归类，具体原因未记录”，不猜测是未命中还是待确认，不拿后来结果反推原发布。旧版名单保持原政策；按新政策生成时，原因未记录不单独否决已知的未归类状态。`state=unavailable`与`phase=unknown`仍表示必要市场证据不足并阻止入选，不与未归类混同；这些状态均不单独覆盖证据完整的核心／候选主要标签。

当日`state`偏弱／弱势，或原始晋级率≤13%且封板率≤57%，立即追加弱势市场提示，不等平滑阶段变更；短线退潮／冰点也作背景提示。提示分别保存具体依据，不再经“无市场防守”或阶段条件间接挡住全体股票。晋级率与封板率仍使用0—1原值，与分类器平滑值分开；已知弱势与必要数据不可判定不能混同。当前实现中“修复”要求改善，不再是兜底，兜底为unclassified。

弱势、偏弱、退潮、冰点及已知原始指标偏弱均不单独限制观察；必要背景未知仍独立标注“市场政策证据不足”，不能因已知弱势而把缺失当作通过。高潮限制、state不可用及phase未知规则保持。市场状态不进入H分数，市场提示或限制不自动删除核心身份；政策未知本身不触发主要标签“证据不足”，主要用途仍按第9.4节判断。韧性无压力／样本有限是尚未受检，不因缺R使完整核心整体变成证据不足；真正的韧性数据缺失仅阻止相关韧性判断，已知较差证据仍保留限制。

### 9.3 位置与成交证据

| 条件 | 日线规则 |
| --- | --- |
| 接近MA5 | `abs(C−MA5)/ATR14≤0.5 AND C≥MA10` |
| 接近MA10 | `abs(C−MA10)/ATR14≤0.5 AND C≥MA20` |
| 位置过热 | `(C−MA5)/ATR14≥2 OR (C−MA20)/ATR14≥4` |
| 日线转强事实 | 收盘突破前一日最高价，且当日跑赢剔除自身后的板块 |
| 当日位置条件 | `C≥MA20 AND NOT 位置过热 AND NOT 当日一字涨停` |
| 观察名单的位置资格 | `C≥MA20 AND NOT 当日一字涨停`，且原位置判断所需输入完整、过热状态可判定；已知过热仅提示 |

ATR须有效为正；突破比较同一复权口径。接近均线只是距离事实，不额外强制所有核心必须回踩，也不构成买点。保留原当日位置判断及过热原值，观察名单另存位置资格，不能把所有位置false或unknown整体放行。仅过热不再使主要用途变为等待位置确认；跌破MA20或一字涨停仍按等待规则处理。必要位置输入缺失仍不可入选。风险和身份的恢复各按自身规则。

日线可陈述原始OHLC、成交量额、实际涨跌停价，以及按明确规则算出的日线事实和指标。按现有价格精度规则原始O/H/L/C均在实际涨停价时，可标一字涨停和连续天数；仅凭`low<涨停价`不能证明首次封板后开板。没有时序证据时，开板次数、封板持续时间和盘口排队状态均未知；收盘涨停不等于“全天封死”，也不证明某笔委托无法成交。

一字涨停保留核心地位，但标交易条件受限并等待位置条件；其他收盘涨停注明涨停事实与排队情况未知。未取得有效五档不得写封单较大；成交额不是封单额。不同涨跌幅制度单列，成交仍取决于委托价格、时间、方向和对手方，不能从制度差异推断可以成交。

若晚报提及交易条件，须明确下一交易日开盘、排队和实际成交尚待确认，不能将其作为全体股票统一的观察目标。只有观察名单的位置资格已知不满足才进入等待位置确认。后续观察侧重同题材相对强弱、核心地位延续、价格与均线关系、热度及压力后的表现；若写日线转强条件，必须等待后续收盘，不称系统已盘中验证。

### 9.4 唯一主要标签的判定顺序

先计算并保留全部底层事实；再对当前已确认身份、新晋／补涨候选、早期观察对象，以及原跟踪对象的当前风险、身份失效或必要证据缺口，按下表顺序取首个满足项。当前股票对象必须实际命中一项；仅需交代“观察资格结束”等变化而没有当前标签的旧对象进入独立事件表，不计入七类股票数。已知退出范围的旧对象仅在历史退出事件展示。

| 优先级 | 主要标签 | 完整判定 |
| --- | --- | --- |
| 1 | 风险暂停 | 任一已知风险命中，或既有暂停尚未满足全部解除条件；同时保留地位失效等事实 |
| 2 | 地位失效 | 无未解除风险暂停，最后有效核心身份当日失效且没有其他有效身份；此后若重新进入候选阶段按当前资格分类，旧失效事实留在事件表，不永久占用主要标签 |
| 3 | 证据不足 | 无上项，且当前要呈现的核心／候选资格、确认或维持判断本身为unknown；明确说明该判断的必要证据缺口，风险或市场政策unknown不单独触发此项 |
| 4 | 等待位置确认 | 有已确认核心或当前新晋／补涨候选资格，观察名单的位置资格已知不满足；仅过热不触发本项，市场／板块／身份问题仍另列 |
| 5 | 已确认核心跟踪 | 至少一类有效已确认核心且其当前身份判断明确，无更高优先项；可同时带风险／市场政策证据不足、分歧、板块暂停、压力未成熟等限制 |
| 6 | 新增观察候选 | 当前满足新晋核心候选或补涨候选资格，尚未确认核心，无更高优先项；保留角色和限制 |
| 7 | 早期变化观察 | 当日符合第8.2节，但无新晋／补涨候选或核心资格；不进入新增候选精选 |

“新增观察候选”指**本轮当前仍处于候选阶段**，不是每天第一次入榜，也不是开仓信号；另存`candidate_first_entered_at`及`new_today`变化事件。首次进入日期不因连续展示而重置；资格明确终止后再次进入，记录新的候选阶段及与前次关系。

证据不足按判断对象限定：缺补涨历史不能盖掉证据完整的趋势核心；概念不可算不能抹掉独立完整的行业核心；无压力样本不算证据缺失。若某项当前判断已被明确false否定，不借其他缺数把它改为unknown。主要标签是呈现优先级，不是七类底层事实互斥。

主要标签“证据不足”与独立限制“当前风险证据不足”“市场政策证据不足”分别保存和呈现。核心当前身份判断完整、无更高优先项时，保留“已确认核心跟踪”；当前新晋／补涨候选资格完整且尚未确认核心、无更高优先项时，保留“新增观察候选”。仅风险或政策未知时，将限制紧邻主要标签展示，两者均不得进入精选。观察名单的位置资格已知不满足仍按优先级4归为等待位置确认，已知过热只作提示，并列展示风险／政策限制；任一风险true或既有暂停未解除仍按优先级1处理。

历史已确认不等于当前维持判断完整：无更高优先项时，当前维持为unknown且没有另一类独立完整的有效已确认核心身份，主要标签为证据不足，保留历史确认事实并标身份待核验；另一类身份完整时可按该身份继续跟踪，待核验身份单列。同一缺失输入若同时使风险与核心／候选自身判断为unknown，仍按上述判断对象范围适用优先级3；只有未知不影响自身必要判断时，才仅作为风险／政策限制。维持条件已有明确false时继续按第7节累计失败或呈现分歧，不因其他缺数改成unknown。

普通未入选股票不必分到七类。曾入选而当前无资格、无身份失效事件的，记录“观察资格结束”变化，保留当日退出记录，不虚构“地位失效”。风险解除后重新按全表分类，不自动恢复旧标签。

### 9.5 判断依赖与缺失传播

判断按股票、概念／行业、关联板块、轮次／试探链、类型和规则版本定位，不设一个覆盖全股的“存在空值”开关。对每条身份路径，已有未结束身份区间时评估维持／失效，待核验不改走新晋路径；没有该区间的当日新晋评估进入／确认。补涨按自己的条件评估。只有当前适用路径参与主要用途归并，未触发的类型或无关分项不成为该路径的必要输入。以下列直接依赖，数值分项再沿第3—8节公式追溯原始输入；计算顺序为输入与组 → 基准／分项／排名 → 各判断及生命周期 → 主要用途 → 精选。

| 判断／计算对象 | 必要输入或上游结果 | 明确不成立与缺失处理 |
| --- | --- | --- |
| 基础资格与本次比较组 | 范围／ST／交易状态、有效预热与近端价格、20日成交额、完整分类观察 | 已知不合格与资格未知分开；按3.3建组后不能删缺分成员。组人数不足或必要行情缺失使相应基准／排名不可计算，不伪造为零收益或垫底名次 |
| 板块入口、轮次与主归属 | 本策略Top5记录、`R_s,20/X_s,5/X_s,20/P_sector`及分母、分类关系、已有轮次和连续计数 | 沿4.1的AND／OR与4.2状态规则；例如已知足够Top5次数可满足情绪入口，未用到的趋势分位缺失不否定该入口；共同超额仍须单独检查 |
| 连板核心当日进入 | 基础资格、`S/I/L/H_b`及完整同类型排名、近5日真实连板、`R20/X20/C/MA20` | 必要门槛任一明确false则进入false；否则必要证据缺失为unknown，不依赖完整韧性`R` |
| 趋势核心当日进入 | 基础资格、`S/L/V/H_t`及完整同类型排名、`R20/X20/C/MA20` | 同上；不依赖`I`或连板记录，不能因它们缺失破坏完整趋势判断 |
| 核心正式确认 | 当日同类型进入、同一证据链最近3日完整判定、当日主归属及已确认活跃轮次 | 完整记录下次数不足或当日必要门控不成立为false；没有明确false但必要日记录缺失为unknown。缺日不补false、不跨日凑次数 |
| 核心维持／失效 | 对应`H/L`及前3排名、`R20/X20/C/MA20`、基础资格、独立立即失效事实、原身份及失败／恢复计数 | 已知false按7.1计数，独立立即失效优先；其余必要证据缺失为unknown。停牌及遗留窗口按7.1待核验例外，不冻结其他明确失败 |
| 当前风险命中 | 原始价与实际跌停规则；复权价格、MA20、ATR；相邻两日跌幅及各自前日ATR；资格状态 | 各分支分别计算后OR：任一true即风险命中；无true但有必要unknown才为unknown；全false才是`risk_now=false` |
| 既有风险暂停解除 | 原暂停事实、连续2日价格分支全false、`C≥MA20/X5>0`、适用时的交易资格恢复证据 | 必要解除项未满足时保留暂停；unknown打断恢复计数。`risk_now=false`不能单独证明暂停已解除 |
| 市场政策通过 | `state/phase`、原始晋级率与封板率，以及9.2的即时限制 | 高潮仍不通过；unclassified及弱势防守只提示。无明确阻断但必要背景未知则unknown，原始晋级率与封板率构成的弱势判断不可判定时仍不得入选。已知phase缺少`phase_reason`只使解释未记录，不把phase重新改为unknown |
| 位置事实与观察资格 | `C/MA5/MA20/ATR`及当日原始OHLC与涨停规则，按9.3计算过热和一字涨停 | 原位置事实保留；观察资格只将已知过热转为提示，其他已知失败及必要输入缺失仍阻止入选，不以缺ATR证明位置合适 |
| 韧性与相应观察限制 | 完整20日压力判定、同组收益、所需ATR、回撤与成熟窗口、已知分项及样本数 | 无压力／样本有限与输入缺失分开。前者允许`R=null`且按6.5保留已知限制；后者只使依赖它的判断未知，不改变地位分。不能用`R`是否为空作为统一门控 |
| 补涨及持续确认 | 当前轮次／归属、`k`及5日有效期、`k−1`当时组与60%分位、全部参照身份区间和逐日有效性、`R5/a/H_e/L/X5/C/MA20`、本人核心状态；持续确认另需最近3日判定 | 先对逐条参照按三态OR，再与其他条件AND；任一独立false可否定补涨。参照未知不覆盖另一条完整true，持续记录缺失不补成未成立 |
| 观察名单资格 | 当前可呈现身份／候选、观察位置资格、当前风险及暂停解除、市场与板块门控、维持和韧性限制、补涨附加门控 | 市场未归类、弱势背景、压力未结束、位置过热只提示；其余适用门控须明确通过，必要unknown仍待核验。名额分配在资格判断之后，不改变底层真值 |

每个适用判断保存真值／计算状态、全部已知失败原因、未知原因及输入引用；AND的false和OR的true可以决定结果，但不删除其他缺口。数值不可计算用空值及原因表达，不把它本身等同布尔false。本表负责判断级路由；分项计算及其输入缺失原因由第3—8节对应计算负责，判断层引用其结果，不再复制一套分项缺失分支。实现使用上述领域判断与显式依赖即可，无需为此新增通用依赖图引擎。

完整记录下确认false但当日进入true，保留候选；确认unknown时仍保存当日新晋事实并注明确认待核验，本条进入true不能绕过本条确认缺口。没有既有核心维持缺口时，另一条独立完整的候选／核心路径可以支持其对应主要用途，否则按9.4优先级3呈现证据不足。已有核心维持unknown则严格沿9.4处理：只有另一条独立完整的有效已确认核心身份可避免该维持缺口导致主要标签证据不足，普通候选不能替代它。已有完整趋势身份时，无关连板进入或补涨unknown不得覆盖它；概念与行业分别评估，不能拼接两条路径的分项来制造完整身份。

## 10 晚报观察名单、名额与统计

完整计算保存所有可计算股票、身份、候选、限制和排除原因；页面仅展示最终入选股票。入选最多5只、允许0只，不保证每天产生入选结果，也不为凑数放宽条件。早期观察、风险和失效事件独立归档，不挤入新增候选精选。

观察名单资格：主要标签为已确认核心跟踪或新增观察候选；第9.3节观察位置资格已知满足，当前风险已知通过，必要市场依据可判定、`state≠unavailable`且`phase`不属于高潮或unknown，板块活跃，无核心维持不足、韧性整体或局部较差等限制。未归类（未命中或候选待确认）、弱势市场（包括偏弱、退潮、冰点及原始晋级率／封板率同时偏低）、压力进行中、已知位置过热均只提示；这些背景同时存在也不单独否决。风险或其他必要证据未知时仍不得入选，不能仅凭主要标签通过门控。韧性尚未受检／样本有限可进入，但紧邻标注。补涨资格和附加政策保持：须持续确认且背景为短线主升，其他阶段不借通用提示政策绕过该要求。没有入选不影响完整核心统计。

“当前风险已知通过”明确指`risk_now=false`且不存在尚未解除的暂停；`risk_now=unknown`不通过精选门控。韧性尚未受检／样本有限的允许政策以必要输入可判定且无已知限制为前提；原始输入缺失导致相关限制无法判断时，该门控为unknown，也不精选，但不因此改写完整核心身份。ATR缺失还可能同时影响风险、位置和韧性，须保留各条实际依赖原因，不能全部归结为单一风险缺口。

**零精选的说明与频率。** 当前没有实测依据预测零精选出现的频率，“允许0只”是明确产品行为。已发布报告为0只时，摘要说明本期暂无符合条件的观察股票，并分列没有完整核心／候选、已知风险／市场／位置等限制、必要证据不足及混合原因；完整跟踪记录保留在归档。只有存在其余精选条件均明确通过、仅风险核验未知的对象，且其余同类可选对象也都被这一缺口阻断时，才使用“今日因风险数据缺失无精选”，附对象数与缺失分支；其他阻断原因仍并列披露，不把ATR造成的位置未知隐藏掉。未生成、失败和依赖未就绪单列，不能计作有效0精选。

按全部已发布报告日记录零精选日数／报告日数，实时原发布按量化交易日去重，修订与研究另表，不重复计入同日版本。另记录零精选且存在“仅风险未知阻断”对象的日数、风险未知阻断对象数及同时有其他失败／未知的对象数；对象以名额分配前的完整身份／候选路径为起点，股票去重。各比率附分母，零分母不可计算，发布失败日及数据覆盖另列。这些统计用于评估可用性，不以减少空结果本身证明规则更好，也不据此自动把unknown放行。

去重前先按概念／行业、关联板块及身份／候选类型保存各路径的资格结果和阻断原因，再按股票汇总。第9.4节的全股主要用途与共有限制仍须满足；在此前提下，任一完整路径通过全部精选资格，该股即具备名额分配前资格，不被另一条路径的局部阻断否定。没有可用通过路径才计为资格阻断；篇幅名额未分配另列，行业路径仍按后文补充顺序与名额处理。

同股各路径原因带路径标识并列保留，不合并成一条实际不存在的原因链，也不跨路径拼接通过项。“仅风险未知”须在同一条路径上满足其余条件全部通过；股票级原因统计保留对应路径，同一原因类别内同股只计一次，不同原因类别可重叠，不能相加当作阻断股票总数。

确定性分配：

1. 概念先按第4.3节板块顺序轮流取一只，第二轮才取第二只；单一主归属板块最多2只。每个板块优先已确认连板代表，再已确认趋势代表，再新晋候选，最后补涨；同类使用第5节排序。双重身份只占一个位置，第二只优先补不同类型。
2. 概念选择结束或达到5只即止；不足5只时，以同样顺序由二级行业补充，行业来源总计最多2只、单行业仍最多2只。与已选股票重复的不占第二名额，附行业身份后继续找下一只；没有合格补充则留空。
3. 补涨合计最多1只，计入总额，不强制预留。所有股票总计≤5、每主要板块≤2、行业补充≤2；不混排H_b／H_t／H_e成全市场统一分。

这些只是篇幅约束，**不等于行业集中度或重叠概念风险控制**。板块重叠时披露共享成员或关联方向，不把同一批股票写成独立资金证据。

归档统计以股票去重：七类主要标签计数总和等于当前报告对象数；双身份另作可重叠统计，不与七类加总。失效／换位／风险等事件按事件计数，不能与股票数混称。历史退出对象与当前范围内对象分别计数。页面只显示最终入选股票，不改变这些完整归档统计。

完整归档必须保留范围股票数、基础合格数、实际可评分数、资格不明／缺数据／不达标数；第3.3节按制度区分的成交额门槛前数、可判定数、通过／不通过／证据不足数及两个分别命名的比率；概念／行业覆盖、入口和轮次活跃／暂停／结束数；首次确认、分歧、风险、失效变化。已确认核心的关键变化即使不在5只精选中，也须保存于事件记录；这些内部审计不再逐项展开在阅读页面。

停牌影响另披露当日停牌及复牌窗口排除数、排除后仍可计算／人数不足的板块数、本人停牌与同板块成员停牌相关的待核验身份数，不能把保留历史跟踪记录称为当日资格已验证。正常成员仍可计算时展示调整后成员数；确有中断时按第15.1.4节口径报告频率和时长，未知状态单列。

## 11 晚报内容与站内页面

### 11.1 内容结构

2026-11-03用户明确选择“仅最终入选股票，最多5只”，随后确认名单用于后续观察，市场未归类、弱势市场、压力未结束和位置过热改为提示。本节替换原先面向研究的完整明细页要求；后台全量计算、核心识别和归档不因页面简化而删减。

正文只包含：

1. **报告日期与简短背景**：报告实际日期、下一观察日、本期入选数，以及已有市场事实的简短说明。来源不足时直接说明，不能将旧报告或未知状态写成今日结论。
2. **后续观察名单**：只按后端`selected`名单及其顺序显示，最多5只，每股只出现一次。没有入选时显示暂无符合条件的观察股票及真实原因，不展示中间候选、风险暂停、证据不足或失效对象来填充名单。已知过热、压力未结束、市场未归类和弱势市场可以与入选同时存在，清楚展示提示，不写成“尚未满足入选”。
3. **必要说明**：影响阅读和入选股票判断的数据限制默认可读；生成时间、版本等辅助信息可放在简短报告说明中。原始评分、全量覆盖统计、身份区间和事件证据继续留在归档，不在此页提供完整明细或“显示全部”入口。

每股采用易读的几行内容：名称／代码及入选题材 → 一句值得跟踪的原因 → 少量关键数据 → 当前需要留意的条件与后续观察事项。原因只依据已归档的入选路径，不用高分、其他未选路径或前端重新判断替代后端选择。观察事项不表述为盈利保证或必须先满足才能被观察的交易条件。

关键数据优先为不复权收盘价、5日／20日涨幅、当日成交额，通常不超过4项。价格明确属于报告日，不称当前报价；比例与人民币金额沿用既有单位转换。缺值不能伪装成0，不通过前端补造买点、止损或未归档的交易条件。

不展示“主要用途”“身份”“轮次”等内部分类选择器，不逐项列地位分、韧性分项或市场统计。入选股票的重要风险、缺数与等待条件用通俗中文去重呈现，不为简短而隐藏已知风险。没有可核验的入选理由时直接说明未记录，不猜测身份或因果。

页面文案只组织同一结构化结果中的事实；选股、评分和排序仍由后端负责。参考图片仅用于紧凑排版，不导入图片中的策略参数或交易建议。

### 11.2 导航与布局

页面路径`/evening-report`，页面与侧栏名称“每日晚报”，入口默认置于看板上方第一项。保留既有个人菜单排序与隐藏设置，不重置其余菜单。

页面顶部保留日期、报告版本、生成状态与刷新。默认选择最新已发布晚报并显著显示实际日期。当日未就绪时独立提示“今日等待数据”，不得把旧日期改成今天。指定日期未生成显示该日期状态，不偷偷回退。原发布与修订版均可查看；研究探索结果与正式报告隔离。

桌面与窄屏均以简洁的逐股多行记录为主，沿用项目主题。每股独立分组，以少量间距或分隔线区分，避免大型指标卡片墙、宽表和重复内容。名称、原因、数据和操作可直接阅读，窄屏自然换行，不依赖横向滚动。

切日期或版本时关闭旧股票弹窗，不串用上一报告事实。管理员生成／重建和任务状态保留，但与主要阅读内容分开。验收包括：仅最终名单、空结果不回退中间候选、入选顺序、单股不重复、价格／涨幅／成交额口径、必要限制、当前行情和自选交互、日期版本切换以及桌面／窄屏布局。

### 11.3 行情与自选复用

股票名按钮或“查看当前行情”打开 [StockPreviewDialog](../frontend/src/components/StockPreviewDialog.tsx)，按当前可见股票列表提供`navList/onNavigate`。该组件没有报告日回放参数，历史晚报也只能称“查看当前行情”，不得把弹窗最新报价当成报告当时证据。报告行内数据仍固定为报告版本。复用已有日K／分时、名称和股票操作，不新造平行行情组件。

“加入自选”复用 [WatchlistAddMenu](../frontend/src/components/WatchlistAddMenu.tsx) 和统一 [API](../frontend/src/lib/api.ts)，支持现有分组。用`QK.watchlist`一次共享查询识别“已在自选”；已存在时不重复提交。当前添加接口会更新加入时间、备注和顺序，不能把重复调用当完全无副作用的幂等操作。

提交期间禁用对应按钮；成功更新`QK.watchlist`及`['watchlist-enriched']`前缀缓存；失败提供可见原因和重试，保留所选分组。分组列表沿用现有加载／失败／键盘行为。历史报告中最终入选的股票仍可由用户主动加入自选，旁注明其报告日期，不表示今天仍满足筛选资格。现有自选接口不校验本策略的ST／板块范围，本需求也不收窄通用自选范围或另造交易资格门控。

报告为共享公共市场内容；自选与分组始终属于当前账号，不从报告继承他人状态，不因切换报告自动添加。沿用 [AuthBoundary](../frontend/src/components/AuthBoundary.tsx)、会话请求封装和账号缓存隔离，不能从请求参数选择owner。

## 12 数据接口、存储与缓存边界

后端服务负责统一计算、状态推进、摘要和归档；API薄层校验日期、模式与权限。建议新增`/api/evening-report`资源：日期列表与状态查询、指定交易日／版本详情，以及管理员提交重建任务和查看任务。具体端点按现有API约定落地，返回完成结果或JobStore任务标识，读取不得隐式触发采集或重建。

结果至少保存：报告ID／修订父版本、实时或研究模式、t／T／截点／生成时间、核心规则、范围与观察名单政策版本、输入引用与完整性、分类来源／层级／取得时间／成员增减、比较组及各实际涨跌幅制度成员数、板块排名及分母、轮次与归属、全部地位分及原值、韧性样本和分项、当前风险命中／解除计数、位置和交易证据、生命周期事件、主要用途及限制、完整统计和精选理由。

同时保存第8.1节补涨参照清单、参照身份区间和连续性证据，第9.2节同次分类产生的原因／待确认候选／计数及其可用性，以及第3.3节成交额门槛覆盖的分子、分母和各状态计数。字段缺失时明确标明未记录，不从未来状态或筛选后的名单补造当时依据。

第9.5节的适用判断逐项保存结果、失败／未知原因及输入引用，主要标签、身份事实、全部限制与精选阻断原因分别提供给前端；不能只返回主标签字符串后让页面猜测其他事实。分类输入另存本轮观察的取得时间、源发布时间／业务截至日及其未知状态、来源版本和完整性依据，引用本轮验收的成员观察而非通用合并表的当前内容；原发布成员不随下次同步改变。

停牌证据至少留存股票、适用交易日、确认状态与依据、来源／版本、取得时间；同时保存本次建组排除原因、最终成员及停牌相关待核验原因。现有盘后汇总的停牌总数不能替代逐股证据；历史重放需使用当时已知记录或另行核验的时点资料，事后查询不改写原发布。该轻量记录纳入晚报输入就绪与归档引用，无需复制行情或冻结额外副本。

保存必要的成员观察和轻量计算证据，行情复用既有仓库；不复制整套行情、不新增无具体事故依据的hash／冻结副本。无法恢复原始输入时如实标记，不能宣称精确重算。身份键、规则版本、观察名单政策版本、报告版本使用现有持久化机制支持可追溯性。本次仅改变名单政策，保留核心规则版本`evening-v1`，独立保存`selection_policy_version=observation-v3`（v2将未归类、压力未结束和过热转为提示，v3进一步将弱势市场转为提示）；历史归档缺少此字段按旧政策读取，不补写新政策。任务去重、修订复用及分支清单必须包含政策版本，防止将旧名单误当新结果；核心状态只按未变化的核心规则和范围版本衔接，不因本次提示调整重新冷启动。

统一公共规则的结果和固定摘要共享保存，长期保留实时原发布、事件和修订关系，不套用个人AI报告20份上限。账号自选、分组、导航设置沿用各自私有存储。若将来允许个人策略参数，才另行定义隔离契约，不在本设计预置可配置平台。

[api.ts](../frontend/src/lib/api.ts)集中请求与类型，[queryKeys.ts](../frontend/src/lib/queryKeys.ts)集中查询键：模式、日期、报告版本及影响结果的范围／规则／名单政策进入任务结果身份；同一页共享详情，不为每只股票请求分数。缓存读归档结果，不重复扫全市场。

写入链路按“构建完整结果 → 原子归档／切换当前版本 → 共享更新事件 → 精确失效日期列表、对应晚报详情及任务状态”执行。复用现有generation与`data_updated`机制，实施时检查后端文件、内存缓存、跨进程可见性和前端失效。自选成功仅刷新自选相关缓存，不触发晚报重算；实时行情更新也不改历史报告事实。

## 13 初始化、盘后调度与失败恢复

### 13.1 初始化与恢复证据

先验收输入与指标预热，再逐日保存实时观察。冷启动可立即给完整的当前特征与早期候选，但轮次、核心持续和补涨先后需满足本文件的记录条件，不为了首日满名单补造过去。

停机恢复只在历史决策截点前已保存的完整证据上补算缺失计算，标明实际计算时间和“恢复计算、当时未发布”；它不改变已有原发布。没有当时证据的日期记unknown并打断相关连续计数，不用事后取得的当前快照跨缺日拼接。允许用可验证时点资料做独立研究重放，但不冒充实时发布历史。

同日截点之后取得的新证据，如仍用于当晚修订，须形成新截点、新版本并保留原发布及差异。对过去日期的修订从最早受影响日顺序生成单独修订／研究分支，不更改“当时发布”列表；该分支完成后才能整体查看，期间不混新旧分数／状态。后来取得的历史资料不能反向补齐实时原分支的连续确认。核心识别规则升级隔离版本，实时新规则重新积累确认；研究重放可另查，不能把旧核心规则前两日与新核心规则今天拼成确认。仅观察名单政策变化时，核心识别与范围相同的既有状态继续衔接；已有原发布不自动改写，需要新政策结果时通过独立修订生成并保留原版。

### 13.2 盘后依赖与触发

依赖顺序：正式行情、因子与指标和核心指数验收 → 本轮概念／行业完整观察提交与验收 → 环境／阶段／同日主线完成 → 本策略范围主线、全池评分与状态 → 晚报原子归档并发布共享更新。分类就绪以第3.3节观察契约为准，不以旧文件存在、仅一表成功或预取完成代替；本轮未就绪不生成正式晚报，供应商业务日期滞后另作披露。

实施时在现有步骤8完成后保存本晚报必需输入的就绪记录，引用已经提交且验收通过的数据版本与分类观察；不提前使用仅预取的数据。晚报不以现有步骤13或整条盘后任务成功为前提，因为后续分钟、盘口、榜单步骤可能失败。原管道退出并释放写入槽后，collector依据该就绪记录提交独立晚报任务；后续非依赖步骤失败不抹掉就绪记录，也不阻止晚报生成。

晚报任务重新取得既有写入槽，核对输入版本未被改写，再计算、独立归档并发布共享更新。版本变化则等待新的就绪记录，不在修订中的输入上发布。这里只保存轻量依赖状态和输入引用，不复制行情；现有管道只会整条重试，因此“晚报单步重试”是此次实施需新增的任务编排，不能误称已有能力。保持模拟盘、分钟和榜单本身的原有顺序与错误语义。

晚报不依赖分钟、五档、龙虎榜、新闻或AI成功；既有市场复盘与晚报分别标明自身状态。晚报失败不能把旧报告挂上新日期，也不回滚已验收行情。管道手动取消时不自动派生新的晚报任务，管理员明确恢复后再按依赖证据运行。

采用**输入就绪即进入生成队列、写入槽可用后生成**，不再另设18:00或晨报定时器。复用盘后管道16:00起、每15分钟检查、最后23:45以及已有延后配置；这只是检查窗口，不承诺数据固定时间就绪。晚报生成失败在既有窗口内重试本步骤，复用已经完成的正式输入，不重复无关采集。collector重启恢复任务；跨日不自动冒充当晚完成，管理员可明确补建并显示迟到时间。

读取页面和普通刷新只读，不占写入槽。重建通过collector、JobStore、唯一写入槽和既有重任务容量控制，计算批量读取、不在行情回调线程重算。取消检查放在批次和提交前，原子提交期间保持一致性，最后释放资源。实施新增步骤须同步 [盘后同步约定](postmarket-pipeline.md) 和对应测试，本次不修改管道代码。

### 13.3 状态与幂等

共享逻辑任务由模式、量化日期、范围、核心规则、观察名单政策和输入版本确定。状态：等待数据、可生成、生成中、已发布、失败、已取消；修订版保留父版本并独立状态。同输入重试复用已完成结果，不重复追加确认日、轮次事件或报告版本。

手动取消后停止该日期同一任务的自动重试；管理员显式重试才恢复，次日正常调度不受影响。失败保留原因和最后成功版本，重启按持久任务状态恢复。提交中断只能出现完整旧版本或完整新版本，不能出现有摘要却无股票明细的“成功”。

不新增外部投递队列、通知渠道状态、邮件或Webhook配置。完整成功的定义是结构化结果、固定摘要和页面读取一致且可追溯；不以消息送达或模型生成作为完成条件。

## 15 研究参数与效果评价

本功能以观察价值、事实准确性、核心识别与跟踪连续性为目标；本次验收不要求证明赚钱或提高收益率。以下收益、成交与参数实验是可选的后续研究，保留方法约定，但不作为本次开发的前置条件，也不据此调整名单以追求样本内盈利。观察质量可通过发现延迟、覆盖、身份变化解释、提示完整性和持续记录评估；结果好坏不能只按名单是否非空判断。

### 15.1 参数地位与事前实验

所有数值窗口、权重、分数线、1亿元、12%、ATR倍数、5%跌幅、连续天数、90分位与最小样本均为主观研究初值，尚未校准。名额是产品篇幅决定，不能当作收益参数或风险预算。参数与单位绑定规则版本，调整后同步重算阈值解释与权重占比。

当前公式有效权重：`H_b`中S+I为`(0.25+0.30)/0.80=68.75%`；`H_t`中V为`0.10/0.75≈13.33%`；`H_e`中J+A为`(0.35+0.25)/0.80=75%`。这些只描述当前版本，不是永久约束。L也包含价格信息，需检查重复强调；V是绝对成交规模百分位，不能据此证明放量确认或缩量上涨不可靠。

实验先登记对象、参数、数据时期、样本定义、尺度、准入策略和评价指标，记录全部尝试，不只保留最好结果。基准包括同范围最高连板代表、单纯20日强度，以及本设计。

- **删项比较**：明确删除分项、剩余权重与归一化。主比较采用预先固定的可比选择比例：在共同可计算样本内按各方法排名取10%，并列按同一代码顺序截取；保留其他非分数条件，区分原始排序诊断与完整状态策略评价。整数取`ceil(0.1N)`且至少1；N不足20不做该比较。该研究选择不替代生产75分规则。
- 对当前线性分，重新归一值等于保留原权重值除以剩余权重和，排序相同。额外固定旧75分阈值的实验只作政策压力测试，入选数差异不能直接解释为删项信息增量。
- **韧性增量**先关闭其对观察限制／精选政策的影响，H分数与权重不变；当前价格和资格风险规则仍执行。不得“移除韧性后给H重新分权重”。
- **ATR对照**固定股票、压力日、成员、窗口和样本，比较原始v与旧clip(v,1%,5%)的z、D_score、C_score、F_score、R，并断言win_ratio不变；固定其他规则，不能把样本变化误当尺度影响。z裁剪单独登记，不与v裁剪混用。
- **有限敏感性**一次变一类参数：分数线±5分、连续日数±1日、比例／金额／倍数阈值±10%和±20%、权重单项乘0.8或1.2再归一；非法组合跳过并记录。比较覆盖、名单重合、换手、确认延迟及后续表现。敏感是警报，不单独证明过拟合；稳定也不证明盈利。

#### 15.1.1 制度口径对照：当前混排与方案A

首轮只比较当前正式混排与**方案A：仅将`L`的两个收益百分位按板块内实际涨跌幅制度分层，再对完整板块统一排名**。它检验收益百分位分层的影响，不声称整个模型已经制度中性。实验独立于正式发布，按第3.4、15.2节使用严格时点资料或真实前向记录；固定日期、完整成员、原始输入、市场背景、板块轮次、主归属规则及其他参数，不用当前分类补造历史。

对每个交易日按当日截点已知的实际制度划分，制度未知记输入缺失，不按代码前缀或今天制度回填：

```text
G_{s,r}(t) = {i ∈ G_s(t) : regime_i(t) = r}
L_A,i = 0.5P_{s,r}(X_i,20) + 0.3P_{s,r}(X_i,5) + 0.2N(C_i/H60_i;0.85,1)
```

`P_{s,r}`为完整`G_{s,r}(t)`内的百分位，沿用第5.1节升序平均排名公式；`X_i,20/X_i,5`仍相对完整板块剔除自身后的基准计算。方案名A与第5.2节加速分`A`无关，后者公式不变。

| 决策项 | 当前混排基线 | 方案A |
| --- | --- | --- |
| `L`中的收益百分位 | 完整`G_s(t)`跨制度混排 | 同板块同制度的`G_{s,r}(t)` |
| `X20/X5`的基准 | 完整板块剔除自身 | 相同，不拆分收益基准 |
| 市场百分位`S/J` | 市场同制度组 | 相同 |
| 成交额`V`与其他分项 | 按第5.2节 | 相同，`V`仍在完整板块混排 |
| **进入前2／维持前3** | 每板块、每类型统一排名 | 相同，使用重算后的分数 |
| 排序决胜 | 对应`H`、`L`、原始`X20`、代码 | 相同，不改变决胜口径 |
| 补涨启动前60%分位 | 当时完整板块混排 | 相同 |
| 权重、分数线、持续条件及其他政策 | 当前研究初值 | 相同，不因换分位而重新调参 |
| 板块内制度子组人数 | 无额外门槛，小组仍参与混排 | 每个非空子组至少20只，作为未校准实验门槛 |

方案A用`L_A`重算`H_b/H_t/H_e`及所有依赖判断，包括候选、确认、维持、补涨和主要用途；不把基线的已确认身份或确认计数移植到方案A。两方法从下述同一空状态分别顺序重放，板块入口／轮次等不依赖`L`的事实保持一致。每制度分别取前2／前3、拆分板块收益基准、成交额或补涨60%分位分层均是其他方案，首轮不混入。

**共同起点与初始化。** 实验前按时点资料的可用性登记共同首日`t0`，不根据名单或收益选择起点。处理`t0`前，两方法均无本实验已有的板块试探／轮次、观察关联／主归属、候选阶段、核心身份区间、启动`k`、补涨参照或既有风险暂停，连续确认／失败／恢复／退出计数均为0。它是本实验的冷启动状态，不声称此前实际市场没有核心或风险；不得导入生产或任一方法的既有状态。

两方法从`t0`起读取相同交易日及各截点可得输入，分别推进状态。`t0`之前已可验证且截至计算日可得的正式价格、因子及递推输入，可供第3.2节60根有效日线和21点窗口等数值预热；这不授权生成`t0`前的本策略Top5次数、轮次、身份或启动先后。首轮本策略Top5日证据也从`t0`起累计，之前日期为未观察，不填零次数；既有全市场环境／阶段可使用当日已保存的因果结果，两方法使用同一份外部背景，不复制其中不存在的本策略状态。

不存在统一的“全部初始化完成日”。当日评分在数值输入齐全时即可比较；确认、轮次和补涨按各自必要历史判定，记录不足则标初始化证据不足并按三态规则处理，不把运行前日期补false或把“尚无可证参照”当作完整证据证明没有参照。完整状态结果保留从`t0`起的全部日期、首次候选和初始化限制，不能等两方法都出现核心才开始统计；方案A小组样本不足造成的长期不可计算单列为覆盖限制，不得当作可删除的预热期。

若数值预热或时点资料不足以执行预定区间，只出可支持的评分／覆盖结果，状态与事件指标明确不足，或另行事前登记更晚起点后重新运行；不能用今天分类补齐。若另设正式评价起日，须在看结果前固定，起日前仍从`t0`分别连续重放，到评价起日不重新置空、不复制状态，跨界事件保留首次日期并标左侧历史来源。10日结果窗口不足仍右删失，不因初始化而删掉未确认候选或重置等待时间。

**小样本与完整组。** 20只仅是方案A首轮事前固定的实验参数，不改写正式板块至少6只及市场`P_U`的要求，也不代表统计证据充分。它限制极小子组的粗粒度百分位：5只无并列成员只有0、25、50、75、100五档。人数按完整子组计算，必要分项须完整，不能删掉缺数成员再计数或排名。

任一非空子组不足20只，其两个实验收益百分位不可用于资格判定；相应`L/H`不可完整计算，整个板块相应类型的完整前2／前3不可判定。其他组已算分项可以展示，但不能删掉小组后宣布全板块名次，也不回退混排。必要输入缺失同样遵守完整组规则。记录样本不足、输入缺失及两者同时存在的互斥原因；排名条件为unknown，其他明确false仍按第3.1节合取规则生效。不存在的制度组不要求凑满20只。

这项实验门槛也会使仅6—19只成员的单制度板块失去方案A完整评分资格，须计入覆盖损失，不能归因为分层公式改变了排序。若共同可计算样本不足，报告证据不足与覆盖分布，不根据首轮结果临时放宽门槛；后续门槛变更另行登记实验。

**对照分两部分出表。** 当日评分对照只使用两方法都能完整计算的“板块×交易日×核心类型”，每个单元始终保留完整`G_s(t)`，比较`L`、排序及当日候选资格；不能先取股票交集后重算分位。单制度、至少20只且输入完整的板块，两方法当日分数与排序应一致；这一检查不要求已有生命周期状态相同。

完整状态对照保留全部原始交易日及各方法覆盖状态，独立重放确认、维持、恢复与失效。不得删掉方案A不可计算日后拼接连续条件；当日共同可计算也不代表此前状态历史相同。持续确认与延迟属于完整流程结果，包含评分和覆盖限制的共同影响，不能解释成分层公式的纯增量。

指标按概念／行业、核心类型和制度分别报告；成员观测单位为“板块、交易日、类型、股票”，按当日制度分层并保留子组人数，候选事件按首次候选日制度分层。跨板块重叠和连续日重复不当作独立样本，另披露独立股票、板块和轮次数。各比率零分母均为不可计算。

| 指标 | 首轮固定口径 |
| --- | --- |
| `L`分布 | 在共同可计算单元内按制度报告最小值、25%／50%／75%分位及最大值；分位摘要按升序位置`h=(n−1)q`线性插值，`q`取0.25／0.5／0.75，附各子组人数 |

| 持续确认率 | 各方法按“股票、当时观察关联板块、板块试探／轮次证据链、类型”的首次新晋候选分别建事件队列；首次候选日为0，观察至第10个后续市场交易日。10日确认率为已确认事件数／（已确认＋完整已知未确认事件数）；无确认且必要判定存在unknown、末端未满窗口分别列证据不足、右删失，披露全体候选事件数及各状态数，不静默缩小队列 |
| 确认延迟 | 同一事件的首次确认日减首次候选日，以市场交易日计；10日内未确认、证据不足和右删失单列，不只比较成功者的等待天数 |
| 名单重合 | 共同可计算单元内分别比较前2名单和当日新晋候选名单，使用交集数／并集数；双方均空单列，不记为100%重合；补涨另列，不混入核心类型名单 |
| 覆盖损失 | 按类型计算：基线可完整排名而方案A不可完整排名的板块日数／基线可完整排名的板块日数；零分母不可计算。同时披露两方法可计算数、互斥不可计算原因及受影响的各制度成员观测数，包括被小子组连带影响的大子组 |

候选队列沿第7.1节归集观察关联与试探记录，不以已建立正式主归属／轮次为入队前提；同一试探转正式轮次、观察关联转正式归属时沿用事件和首次候选日，最终未转正的试探也留在队列。实际换板块或证据链结束后重新试探时另建事件，不拼接旧记录。

确认率的分母是候选事件，不是合格成员数。10日结果窗口未满的事件统一右删失，已观测到的确认事实仍可单列，但不提前进入固定10日确认率分母。已届满窗口中，有确认事实即计已确认；无确认且必要判定有unknown才计证据不足，否则计完整已知未确认。各方法候选群不同，其队列内转化率仅作流程表现，不直接解释为算法优劣。

另按共同的“股票、观察关联板块、板块试探／轮次证据链、类型”配对两方法均出现的候选事件，同时报告首次候选日差、首次确认日差及各自等待天数，防止较晚发现被误写为确认更快。仅一方产生候选、仅一方确认、方案A覆盖不足及观察窗未满均单列，不因不可配对而删除。研究结果同时保留全部样本的覆盖代价和共同可计算样本的评分差异。

#### 15.1.2 结构破坏的相对偏离对照

正式规则保持第9.1节不变。本实验只比较原`structure_break`与同时要求最小相对MA20偏离的研究分支：

```text
deviation = (MA20_t − C_t) / MA20_t
structure_break_epsilon = (MA20_t − C_t ≥ 2 × ATR14_t) AND (deviation ≥ ε)
```

`ε`为小数制的未校准研究参数，`0<ε<1`，仅用于本实验，不进入正式规则。实验前登记`ε`的具体取值；若比较多个值，须事前列全取值及评价方法，保留全部结果，不先看效果再选择`ε`。同时固定日期、时点输入、股票范围、分组切点、样本披露要求和评价窗口。正式1亿元基础门槛、完整板块混排、ATR时点及原始有效数值、其他风险分支、身份和风险解除规则均不变，不同时调整成交额门槛或启用方案A。

先按同一ATR、MA、价格有效性与预热要求确定可评价范围，ATR不可用及具体原因单列，不用`ε`掩盖数据质量问题。合法极小正ATR仍是可评价样本，不因结果敏感而事后删除；如研究另一个ATR可用性下限，须另行说明尺度、质量依据和样本影响，不与本实验混为一次改变，也不恢复第6节已取消的波动裁剪。

先分别按当日`ATR14/C`、当日实际涨跌幅制度和当时原始股价做单变量分组描述，再检查交叉分组的股票数、日期数及事件数，仅在样本条件满足时做交叉比较。分组切点在实验前固定，不用评价期未来分布选取；原始股价分组不用前复权价格代替。三种维度可能相关，单变量组间差异不能归因为某一制度或波动因素，交叉小样本须明确标注，不合并成独立证据。

两方法报告结构分支日命中率、其他风险分支均明确false时的独立命中率、未知覆盖，以及顺序重放后的首次暂停事件数、持续时间、解除情况和事件后3／5／10日表现。日命中率为结构分支true的股票日数／结构分支可判定的股票日数；独立命中率为结构分支true且其他分支全false的股票日数／结构分支可判定且其他分支全false的股票日数。零分母不可计算，并另列应评估数、可判定数和不可判定原因；首次暂停按事件计数，不能把持续命中的每一天当作新暂停。完整重放保留全部交易日和unknown，结果窗口、缺口与删失沿第15.2节；暂停更少不能直接解释为误报更少，须结合后续修复与回撤等事前指标评价。

**研究后的正式决策。** 本实验须交付“维持现规则／提出将`ε`纳入正式规则／证据不足继续观察”之一及依据，明确关闭或延续这一待决项。执行前登记暂停负担、后续修复与回撤、漏掉持续恶化风险等评价指标及可接受差异，在验证／保留区间检查取舍；没有事先定义的可观察错误标签，不称“误触发率”。仅触发次数减少、样本不足或结论不稳定，不足以支持进入正式规则。若证据支持调整，须形成新规则版本、明确最终`ε`及适用范围、重放状态并同步9.1与验收用例；实验分支不会自动切换正式规则，也不以`ε`掩盖ATR数据质量问题。

#### 15.1.3 成交额门槛的覆盖与敏感性

正式近20日成交额中位数门槛保持1亿元，不直接按制度改线。本实验以第3.3节门槛前池为共同审计起点，按当日制度报告`n_pre`、`n_decidable`、`n_pass`、`n_fail`、`n_unknown`、门槛覆盖率及可判定样本通过率；上游资格不合格和未知另列。先说明各制度成交额分布、数据完整性和覆盖差异，不把制度入选人数不均直接解释为门槛偏向。

门槛敏感性沿用本节金额阈值±10%和±20%的事前范围，1亿元为基线，其他参数固定。每个门槛分别重建`U(t)`、板块成员`M_s/G_s`、个股市场百分位、等权基准、地位分与排名，并重放由这些变化影响的板块入口／轮次、归属、核心／补涨、风险用途和精选结果；不能只对原最终名单增加或删除股票。保留完整日期和各方法覆盖，比较制度覆盖、成员与名单重合、确认及延迟等第15.2节指标，未确认、未知和右删失分别披露。

该实验改变基础池，方案A改变板块内收益百分位，`ε`实验改变当前风险分支；三者分别登记实验配置、各自基线与结果，首轮不叠加。可以复用同一份可验证时点原始数据，但不能直接沿用方案A筛出的共同可计算样本或对照结果，也不能用一项实验的效果替另一项背书。

#### 15.1.4 停牌与跟踪连续性审计

本次决定采用第3.3节建组前排除、全窗口固定剩余组的方案；不同时放宽6只／5只最小样本或21日连续价格要求。已确认的结构性影响是：人数仍充分的板块可以继续计算，临界板块仍会因样本不足待核验，停牌股票自身至少要等停牌日移出近端窗口才能恢复评分。这是对计算规则的判断，不是对实际中断频率的估计。

截至本次设计核验，现有当日覆盖对象包含逐股状态，但任务摘要只保留汇总数，独立停复牌查询不持久化完整历史，行情入库前又会过滤停牌行；当前分类快照也不足以还原当时成员。因此目前**真实停牌相关中断率及持续时间尚未测得**，不能拿日线缺行比例代替。审计消费第12节留存的轻量证据及判断结果，采集与标准化沿既有输入链路完成，不另建停牌数据源；有可验证时点资料时沿同一证据契约重放，否则从前向观察积累，不以当前分类回看宣称完成严格评估。

审计事前固定日期范围、规则版本和应覆盖板块，概念与二级行业分别统计。分母沿第4.1节应覆盖集合，保留当日因停牌跌破人数门槛的板块；按前一市场交易日合格成员数分6、7—10、11—20、20以上及其他／未知组，避免用排除后的组规模隐藏原临界板块。分类或状态证据不足分别保留，不当作无停牌。

| 指标 | 固定口径 |
| --- | --- |
| 停牌暴露与建组影响 | 应覆盖板块中含已确认全天停牌范围成员的板块日数／全部应覆盖板块日数，附状态可判定及未知数；另列昨日合格成员今日因停牌或其窗口遗留缺口退出的数量、最终组规模及排除后仍可计算数，区别无评分资格成员的停牌与实际建组变化 |
| 停牌相关人数不足 | 昨日合格组至少6只、今日不足6只且至少一名昨日合格成员因停牌相关原因退出的板块日数／昨日合格组至少6只且今日仍应覆盖的板块日数；保留其他成员资格变化及未知，称“停牌相关”，不宣称全部由停牌单独造成 |
| 既有核心待核验率 | 前一日存在未结束确认身份、今日维持为unknown的身份日数／前一日全部未结束确认身份日数；按本人停牌、本人复牌窗口、同组人数不足及其他缺口拆列，可并存原因不相加；当日明确失效也留在分母和状态统计中 |

各比率附分子、分母，零分母不可计算；必要状态未知时披露未知量及比例的已知覆盖，不把已确认事件数除全体后声称是完整真实发生率。身份指标补充去重股票数，重叠概念、双类型与连续日不当作独立样本。停牌后排名和身份变化仍遵守第3.4节因果解释边界，不能仅因发生在同一天就归因于剔除成员。

**补涨连续性的额外审计。** 按已观测启动线索建立机会记录，`k`不可验证者单列左边界未知；可验证的同一股票、主归属、轮次和`k`保留`k…k+5`的全部市场交易日，不从最终补涨名单倒推样本。先判条件1、3、4、5：均true的机会日作为条件2覆盖分母，其他条件false、unknown及其数量另列。对此分母报告条件2的true／false／unknown数及比例；unknown再区分仅有停牌／复牌遗留连续性缺口、停牌与其他缺口并存、其他缺口。另列“有停牌参照但另一条完整参照仍支持成立”的数量，不能把任一参照停牌都算作补涨丢失。

对前一日补涨成立的事件跟踪次日true／false／unknown及持续时间，明确不成立的原因包括成为核心、窗口到期和其他条件失败，原因可并存；保留未知、末端右删失、事件数及独立股票数。历史信号与当前判定分别统计，不把转unknown当作历史信号不存在。目前没有足够逐日身份及停牌证据测出这项覆盖损失，不能预言会稀少到何种程度；与核心待核验率一起积累，若需要放宽连续性须另立规则及对照，不能直接把待核验日计为有效日。

首次具备上述证据时报告6—20只板块的覆盖损失、待核验频率及持续时间；在此之前明确未测。若审计显示同组人数不足或复牌窗口等待持续阻断目标跟踪，应依据该结果再评估最小样本或窗口政策，单独登记变更与对照，不静默改为逐日变篮子或停牌零收益。

### 15.2 事件、窗口、样本与基准

研究只使用严格时点数据或真实前向记录，按连板／趋势、当时市场阶段、板块轮次和涨跌幅制度分层。实时与重放分别出表。未来结果仅作评价，不回填特征。

| 指标 | 固定事件与观察定义 |

后续收益评价从事件日收盘到未来收盘，仅为识别指标，不是可执行成交收益。基准与策略用同日期、同制度和同一可比较样本，分别报告未覆盖与数据删失；样本末端不够观察窗时不能填0或删除得不留痕迹。

统计至少披露事件数、独立股票数、板块／轮次数、日期范围、状态与制度分层数、完整／删失数。少于30个完整事件、10只股票或5个板块轮次时只给描述并标样本有限；达到这些初始披露门槛也不代表充分统计功效。股票、概念及时间窗口相关，不能把全部行数当独立样本。

时间上预先固定最早60%交易日为探索、随后20%为验证、最后20%为保留检验；固定3／5／10日指标在分界留足10日结果隔离，评价标签不跨分区。轮次持续、重开间隔及中期失效延迟等没有固定最长期限的指标，在各分区末右删失，不读取下一分区的结束／重开来补齐标签。只有足够时点记录且各段覆盖明确时才运行；不足则继续前向积累，不以当前分类历史回看补足。记录所有试验和规则修改；保留集用于选参后就不再独立，需新的前向区间。

当前情绪平滑为因果计算，缺失重置；仍以逐日截断对照确认研究没有读取未来。不得用完整情绪阶段结束后汇总主线回填早期判断，既有情绪阈值标定区间也不自动算独立样本外。

### 15.3 成交模型与收益评价

没有真实委托结果时，不称“不可成交比例”，使用“按指定成交模型的未成交比例”。一个预登记的保守开盘模型为：信号`t`收盘后形成，`T`尝试开盘买入；已知当时停牌、开盘价达到实际涨停价，或预定滑点后的模型成交价超出当日合法价格范围，均假定模型未成交。其他具有有效开盘价、规则和必要成交资料的机会，按开盘价加预定滑点估计模型成交；必要资料不足为无法判断。开盘涨停的未成交是保守模型假设，不断言真实排队一定失败；不得读取T全天最高／最低价或后来是否开板来决定开盘模型分支。

分母是事前规则生成、原本应尝试执行的全部机会，分列模型成交／模型未成交／资料不足。未知不能算成交、不能直接删除；未成交机会可评价识别效果，不能计作已赚收益。次日尚未开盘的晚报不预知任何分支。

研究执行收益还须预登记资金、委托方向与价格、退出时点、费用、滑点、T+1和跌停等卖出限制；未成交或受限卖出保持在完整路径中。没有这套完整执行契约时，只报告识别指标和机会分布，不输出策略收益率。模型具体费用随研究时适用规则核验，不在此假定真实可成交。

规则正确性与研究效果分别报告：无历史污染、唯一主标签、名额上限可直接验收；未确认率、延迟、超额或轮次持续时间即使算出数字，也不自动证明策略合格，不承诺收益。

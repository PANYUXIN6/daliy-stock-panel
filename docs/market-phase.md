# 短线投机阶段与主线识别

阶段仅描述连板生态，与全 A 广度、量能、指数价格背景分别展示。它不是收益预测、反转确认或仓位建议。现有综合 `state` 及回测过滤契约保留，新增 `unknown` 和 `unclassified` 不改变既有六个枚举的存储值。

完整观测定义与本次验收表见 [情绪观测设计](sentiment-observability.md)。

## 每日梯队指标

`backend/app/services/market_phase.py` 从 `consecutive_limit_ups` 聚合首板、二板以上、三板以上、五板以上家数及梯队完整度。晋级率仅在当前及相邻已覆盖市场日期均有有效连板数的可比较股票池内计算：前日有涨停、当日连板数恰好增加一的数量除以前日涨停池；池不足 10 家返回 null。个股跨停牌/缺行不能冒充昨日观测。调用方提供跨批次 warmup，并保留函数生成的个股前日与市场前日日期依据。没有任何可比较股票时池也为 null，真实空涨停池为 0。市场相邻日期来自本批已覆盖日期，未引入交易日历 I/O；若全市场缺整个交易日仍需盘后完整性验收发现。

`ladder_completeness` 是 2..最高板档位的非空占比；最高板不足 3 或输入缺失时为 null。此字段目前不参与阶段规则。首板/各级连板计数要求当日输入连板数全部有效；即使仅部分股票缺项也保持 null，不将已知子集伪装为完整计数。真实零计数保留为零。

## 描述性阶段规则

各驱动先做 EMA（alpha=1/3），缺失不使用过去值或未来值替代，并重置该驱动 EMA；恢复后从真实观测重新开始。变化条件要求截至当日连续 6 条有效高度、二板宽度、晋级率记录，比较当日与 5 条记录前，不把不足窗口当作完整窗口。

按以下顺序判定（数值均为 EMA）：

| 枚举/显示名 | 条件 |
| --- | --- |
| climax / 短线高热 | 二板以上 ≥50 或首板 ≥220 |
| rally / 短线活跃 | 高度 ≥7、二板以上 ≥15、晋级率 ≥0.23；或高度 ≥5、二板以上 ≥12、晋级率 ≥0.30 |
| ice / 短线低迷 | 高度 ≤4、二板以上 ≤6、首板 ≤24 |
| ebb / 短线退潮 | 5 日前二板以上 ≥12 或高度 ≥6，当前宽度回落且晋级率 ≤0.15；或晋级率 ≤0.13 且封板率 ≤0.57 |
| ignite / 短线启动 | 二板以上较 5 日前增加 ≥3 且当前 ≥8、晋级率 ≥0.20；或高度增加 ≥1 且当前 ≥5、晋级率 ≥0.19 |
| repair / 短线修复 | 二板以上宽度与晋级率均较 5 日前改善，且未命中上述条件 |
| unclassified / 未归类 | 未命中规则，或首次有效候选尚待确认 |
| unknown / 数据不足 | 当日高度、首板或二板宽度缺失 |

具体阶段首次出现及切换都需连续 2 日相同候选。未归类和核心数据缺失立即撤销旧阶段并清空待确认计数，不把昨日活跃/修复沿用到没有证据的当天。缺失晋级率时仍可判定仅依赖宽度的低迷/高热，不可判定依赖晋级率的阶段。

去掉原有全市场弱档否决：短线投机活跃与全市场偏弱可以同时成立，是结构分化。启动没有成交量或价格条件，不能解释成“低位放量”。修复不再是兜底，也不意味着未来收益改善。

阈值沿用项目既有经验参数；旧文档称它们来自 2020-08 至 2026-08 的样本分位，但标定脚本未入库，无法独立复现。历史全样本标定还存在参数选择的前视偏差：序列计算因果不等于阈值已通过样本外验证。旧版段长、占比和案例验收数字不再适用于新算法，本次未重新验证历史表现。

## 主线识别

实现在 `backend/app/services/market_mainline.py`。复用 `rps_rotation` 的概念映射加载，窄扫描 `kline_daily_enriched` 的 symbol/date/consecutive_limit_ups/amount 四列，按 (date, 概念/行业) 聚合：

- `limit_up_count` 涨停家数、`ge2_count` 二板以上家数、`max_boards` 最高板、`boards_sum`、`rungs_filled` 梯队档位数、龙头股（按连板数、成交额排序取第一）。
- 主线分 = 当日截面 rank 归一后 `0.35*涨停数 + 0.25*最高板 + 0.25*梯队档位数 + 0.15*二板宽度`。这是"同板块涨停越多、梯队越完整越是主升主线"判据的直接量化。
- 每概念当日涨停 <3 家不参与排名；每日持久化 top30 到 `data/mainline_history/part.parquet`（upsert 按 date+kind 整日替换）。
- 行业维度取前两级（如 `计算机-软件开发`），作为概念维度的交叉验证。

### 宽基/风格标签过滤

融资融券（~7700 家）、沪深股通（~3300 家）这类超大概念会垄断 top1，需要过滤。配置存于用户偏好（`preferences.json`），市场环境页「过滤」面板可改：

- 成员数上限：默认 600，超过视为宽基/风格标签不参与排名（夹取范围 50-5000）。保留华为概念（2006）、人工智能（2166）等真主题。
- 成员数下限：默认 4（夹取 1-200）。
- 名称黑名单：手动屏蔽任意概念，支持逗号/分号/空格分隔。

修改保存后自动触发全量主线重算（`POST /api/regime/mainline/recompute`，秒级）。API 层为 `PUT /api/preferences/mainline-filter`。

### 快照回填偏差

概念成分为**当前快照回看历史**（本地自 2026-07 起留存，无历史版本）。新纳入指数或改名的个股会出现在旧时段、成分调整会错归属，因此早年主线存在归属漂移，越近越准。此口径限制以 `membership_note` 字段随 API 返回并在页面展示。若后续把 ext 概念同步改为按月累积快照，主线历史精度会逐月自然提升。

## API 与运行

交易日默认北京时间 16:00 的自动盘后管道会在正式行情与指标验收通过后增量计算环境、重标短线投机阶段并刷新当日主线，不受手动 `pipeline_regime_enabled` 开关影响。完整依赖顺序、验收、重试与取消规则见 [盘后同步顺序约定](postmarket-pipeline.md)。市场环境页的空态“环境分析”按钮仍复用下述全量重算接口。

- `GET /api/regime/phases?start&end`：连续阶段段列表（阶段、区间、天数、高度/宽度/晋级率/封板率均值、段内 top 主线）。
- `GET /api/regime/mainline?start&end&top&kind`：窗口内主线排行（top1 天数、日均分、最高板）与每日明细。
- `POST /api/regime/mainline/recompute`：过滤配置变更后的全量重算（两类维度）。
- `POST /api/regime/recompute`：扩展为重算 regime 后自动重标 phase 并回填主线。
- daily pipeline 在 regime 步骤后追加主线增量（复用 `pipeline_regime_enabled` 开关，软失败不阻塞）。

阶段标签由 `regime_builder.refresh_phase_labels` 在每次 regime upsert 后对全量历史重标（仅日级聚合记录）——因为 EMA 与 2 日确认依赖完整序列。

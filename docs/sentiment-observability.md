# 情绪观测：范围、方法与验收

本次将市场总览和市场环境页定位为描述 A 股广度、参与程度、短线投机生态及指数价格背景的历史观测。分项原值、同口径历史分位与数据缺项优先于项目参考评分。不得将观察解释为未来收益、底部确认、卖压耗尽或仓位建议。

## 数据契约

实现入口为 `backend/app/services/sentiment_observations.py`。`sentiment.version=observations-v1`，`as_of` 是日聚合归属日期；`universe` 记录 ST 过滤和停牌剔除规则，`coverage.sample_count` 为样本数，`method_current` 区分当前方法与旧记录。旧记录需要通过既有环境重算更新，不静默视为新方法。

每个 observation 包含 `key/label/group/unit/value/denominator/status`，以及 `percentile/history_sample_count/history_coverage/change_5d/extreme_streak/extreme_side`，并提供 `missing_reason/percentile_reason`。`status=unavailable` 表示原始值不可用，不能补成零或中性值。单位 `%` 是百分数值，`ratio` 是小数比例，`CNY` 是元，`count` 是家数，`points` 为指标点数。覆盖信息另含 `valid_change_count/is_complete_day/is_closed_day/market_coverage_verified/completeness_note`。`is_complete_day` 为兼容字段，仅表示日记录已到收盘口径，不证明全市场覆盖验收通过；当前 `market_coverage_verified=false`。未收盘当日不得输出正式分位，也不能作为后续历史有效样本。全市场覆盖仍需另行验收。

日聚合生成时将 `is_complete_day` 一同持久化。它沿用 enriched 的来源契约：`quote_ts` 缺列或为空表示正式历史日线；非空的实时来源须逐只确认时间戳属于目标日且达到北京时间 15:00，不能由一只较新的股票替其他盘中快照确认收盘。生成时目标日期也必须已经收盘。读取时只接受明确为 `true` 的完成状态；盘中记录不会因越过 15:00 或跨日自动成为正式样本，分位、后续历史样本与 20 日量能窗口均排除它。只有来源更新后重新计算并成功替换记录，才能恢复其正式样本资格。

仓库启动预热、历史缓存与共享最新日快照须保留 `quote_ts`。读取窗口沿用兼容存储 schema，为旧分区缺列插入空值；不能根据最新分区的字段清单裁掉较早分区的来源时间戳，否则盘中记录会在缓存重算时被误认为正式历史。

旧日聚合缺少该字段或值为空时保留原值展示，但收盘口径视为未知，不输出正式分位或计入后续有效历史。既有增量 stale 检测会将这些日期纳入补算，管理员也可显式重算；GET 不迁移、不回填状态。是否需要先补采正式行情仍沿用原同步与完整性流程，不能仅重新标记旧盘中来源。

| 维度 | 分项 | 定义与限制 |
| --- | --- | --- |
| 广度 | 上涨/下跌比例 | 有效涨跌记录为分母；平盘不计入涨或跌，但保留在分母 |
| 广度 | MA20/MA60 上方比例 | 对应均线有效记录为分母，不能用全体样本掩盖覆盖不足 |
| 活跃度 | 总成交额、5/20 日成交额比 | 金额原值及均值比；需要完整 20 条同方法同 ST 设置记录；量能不单向代表乐观 |
| 指数背景 | 60/120 日价格位置、回撤、RSI21 | 仅上证 000001.SH，不代表全 A；回撤保留负号；RSI21 使用收盘价上涨量、下跌量的 21 日简单均值，非 Wilder 平滑，亦非中航模型复现 |
| 投机生态 | 涨跌停比例/家数、触板、封板率、炸板率 | 比例使用对应有效分母；封板/炸板以触板数为分母，零触板不可计算 |
| 外部指标 | 融资买入占比、期权 IV/PCR、行业 ETF 净申购 | 缺少可用数据源，明确 unavailable，不参与伪完整统计；已有 4 只沪深 300 ETF 份额不能冒充行业 ETF 资金流入 |

历史分位只使用当日之前最多 500 条日聚合记录，不包含当天；必须有完整 500 个同版本、同 ST 设置、有效的分项历史值，否则 `percentile=null`。采用并列值中秩（midrank）：`(小于当日值的数量 + 0.5 × 等于当日值的数量) / 500 × 100`。常量序列对应 P50，不会伪造 P100 的持续极端。样本数与覆盖率同步返回；分位高只代表该项数值高，不统一代表情绪好。

`change_5d` 是当前值减 5 条日聚合记录前的同口径值，单位同原值；百分数项是百分点差，小数比例项仍是小数差。不是收益或变化率。极端区间为分位 ≤10 或 ≥90；连续天数按同侧累计，缺失/非极端/切换侧别中断。统计在截取 API 查询区间前计算，页面切换展示窗口不应改写分位或持续天数。这里交易日指已存储日聚合记录；缺整个交易日记录仍需依赖盘后完整性验收发现。

ST 过滤使用当前风险警示名单，回看历史存在身份偏差；停牌代理规则仅剔除成交量明确为零且涨跌幅明确为零的股票；缺失涨跌幅不等同于零。不能把当前股票属性当成历史身份已严格还原。项目参考评分与原有五档 `state` 为兼容保留，缺输入不得伪装为中性或完整得分。

## API 与缓存

`GET /api/regime/history` 仅在返回窗口末日附带 `sentiment`，避免每条历史记录重复传输全部观测；`GET /api/regime/latest` 返回最新日观测。按日期查看使用 `GET /api/regime/observations?date=YYYY-MM-DD`，返回 `{sentiment: ...}`，省略日期取最新日；指定日期不存在时返回 `{sentiment: null}`，不回退成其他日期。分位与连续天数先基于完整日聚合历史计算，再选择目标日。

单日读取共享小型日聚合结果缓存，不扫描全市场行情或复制全部历史观测。缓存依赖持久化文件签名、方法版本、ST 设置、北京时间日期与收盘状态，避免跨配置、跨日或盘中/收盘切换复用错误结果。旧方法记录保留原有环境字段，但观测明确不可用，需走既有重算流程更新。

总览涨跌停卡在五档盘口已就绪时保留原有假涨停／假跌停修正后的计数与封板率；无可用盘口时采用日聚合。该修正不改写持久化情绪观测的日线信号口径。

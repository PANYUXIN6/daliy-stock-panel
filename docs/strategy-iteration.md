# 策略迭代记录

研究时按“假设 → 一项改动 → 同口径回测 → 判断 → 记录”推进。AI 可辅助分析证据和维护代码，回测结论与启用策略由人判断。当前网页不支持生成、修改或执行任意 Python 策略；代码维护入口见 [策略指南](strategy.md)。

## 开始前

记录策略版本、资产类型、数据覆盖、费用、成交时序、研究区间及接受／回退条件，再保存基线结果。留出一段尚未参与调参的数据，在版本定型后独立检验；反复查看留出集再修改策略，会失去独立验证意义。

参数或声明式条件可在页面内调整。Python 模板由维护者在受信任目录修改；个人历史 Python 存档不会自动成为可执行策略。

## 每轮记录

可在自己的研究笔记中按以下格式保留证据，数值取自实际运行：

```text
策略与版本：
研究区间 / 数据版本 / 资产类型：
假设：
本轮改动：
基线 → 本轮：收益、夏普、最大回撤、交易数、胜率、盈亏比
分年与市场环境表现：
敏感性与样本外结果：
接受 / 回退及原因：
无效尝试与下一项假设：
```

优先比较同一区间、同一数据和成本模型的结果。先做扫描与常规回测，拟接受的版本再检查参数敏感性、滚动样本外及蒙卡回撤。交易数明显下降、收益仅集中于个别年份或参数轻微扰动即失效时，应核对是否过拟合。

需要 AI 诊断时，可将上述记录与实际导出结果一起提供，要求每条判断对应可核对的证据、每个修改有可验证的预期；没有证据的想法作为下一轮假设。

## 面板中的对应功能

| 目的 | 入口 |
| --- | --- |
| 扫描与调整参数 | 选股页的策略卡片、信号和叠加条件 |
| 运行与导出 | 策略回测，导出概要和交易明细 |
| 比较评分因子 | 评分策略回测的因子归因 |
| 检验稳健性 | 参数敏感性与步进优化 |
| 保存与复测 | 候选方案与载入复测 |
| 启用观察 | 监控中心配置对应规则 |

接受版本时保留可恢复的参数或代码版本，回退时恢复对应版本并重新加载。停止或换方向时记录无效尝试的原因，避免重复消耗同一段样本。挖掘候选另受 [发布门槛](mining.md#晋级与发布门槛) 约束。

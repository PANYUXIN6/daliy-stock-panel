# 策略指南

选股、回测与监控共用策略引擎和评分口径。页面只运行已加载的受信任策略，以及声明式信号和叠加策略。

## 内置策略

内置策略位于 `backend/app/strategy/builtin/`，每个文件定义元信息、参数与计算入口。趋势、形态、量价、涨停、反转和波动等策略在选股页按资产类型展示；实际清单以页面和引擎注册结果为准。

同目录的因子排名研究模板仅供挖掘 worker 使用，不进入普通选股列表。挖掘候选与发布边界见 [挖掘说明](mining.md)。

## 声明式信号与叠加策略

- 自定义信号由字段、运算符和值组成，支持组合条件及 AI 生成条件；保存后进入统一信号计算通道。
- 叠加策略引用现有策略和信号，沿用参数、基础过滤与评分契约。个人目录中的声明只按字面量解析，不执行任意 Python 表达式。
- 日线、分钟策略分别声明周期；分钟策略依赖所需区间的本地分钟数据，不能把日线数据当作分钟数据运行。

信号定义和个人叠加策略随当前账号保存。目录分别为 `data/users/<user_id>/user_data/custom_signals/` 与 `data/users/<user_id>/strategies/composite/`。

## Python 策略维护

网页中的 Python 策略生成、编辑、保存和发布入口已关闭。维护者部署受信任模板到 `data/strategies/templates/`；引擎读取内置目录、该共享模板目录及当前用户的声明式叠加目录。历史个人 `custom/`、`ai/` Python 文件保留存档，不会因文件存在而自动执行。

维护策略时核对 `META`、资产类型、执行后端、参数、评分方向、数据依赖及进出场时序。常见入口包括 `basic_filter`、`filter_history`、矩阵策略和分钟过滤，各自契约以引擎校验及相邻实现为准。

详细代码参考保存在 [策略开发指南](../backend/app/strategy/prompts/strategy-guide.md) 与同目录提示词中；这些文件仍被生成器和提示词构建器读取。人工维护时需按当前引擎核对，文件中的旧网页操作示例不代表对应入口仍可使用。

## 参数与验证

修改参数后重新运行，核对持久化配置、引擎实例、结果缓存和监控状态。策略 ID 是稳定标识，复制和导入不能覆盖已有文件。

回测检查信号日与可成交时间、T+1、费用、滑点和数据缺口。参数敏感性、样本外验证与候选复测见 [策略迭代](strategy-iteration.md)。

非矩阵日线策略的参数优化先合并各参数组的数据依赖，一次加载共享面板；行情编码与参数无关的评分因子值也只在当前任务内准备一次。每组仍独立计算个人叠加条件、候选集、评分归一化及成交，最终选中参数复用同一份输入。矩阵、复合和分钟策略沿用各自执行路径。复用对象随任务释放，不建立跨账号的因子内容缓存；股票池、日期、资产、覆盖配置或所需列不匹配时拒绝复用。

## 回测抽样检查与版本记录

正式策略回测 worker 调用 `StrategyBacktestService.run_with_evidence`，结果附带 `evidence`；优化和步进试算继续调用轻量 `run`。日线面板、矩阵及分钟策略都在正式信号计算后，对至多三个时间点分别截断、扰动未来输入，并比较截点之前的候选、信号及评分。发现差异后用完全相同输入重算，区分非确定性与未来依赖。检查复用正式计算入口，固定本次已读取的行情、财报、股本、扩展时序值和个人信号定义，不在抽样时重新读取这些文件；日线叠加条件仍在候选评分归一化之前应用。

检查结果包括通过、发现差异、重算错误、输入不足、部分覆盖和取消，不能将未完成或空比较描述为通过。分钟路径只抽取部分交易日；日线与矩阵检查侧重特征和信号，不能证明供应商历史修订、历史股票池及静态维表符合点时口径，也不替代样本外验证。分钟策略和分钟精细成交沿用日内最高价作为建仓日峰值的近似，日线收盘建仓则只以买入价初始化峰值。

版本记录保存本次实际读取数据的内容指纹、规范化参数、策略及子策略定义版本、运行代码和依赖版本。它用于解释“同参数重跑结果变化”究竟来自输入数据、规则还是计算版本；已有 generation 只负责缓存发布一致性，不能在后续重算后还原当次消费的数据内容，也不能区分跨环境相同内容。因此这里增加的是追溯记录，不是新的运行硬门禁。记录不归档全量行情，数据被覆盖后无法仅靠指纹还原；定义在运行中发生变化会单独标记。

记录原子保存到 `data/users/<user_id>/backtest_runs/<run_id>.json`，只能由当前账号通过 `GET /api/backtest/strategy/runs/{run_id}/evidence` 读取。不同账号的同名记录彼此隔离，缺少身份或目录重定向时拒绝访问；落盘失败会在本次结果中说明，旧回测无记录时返回未找到。

### 成交与历史价格规则

- 日线收盘建仓不把买入前的当日最高价纳入移动止损峰值；开盘和分钟建仓保留原有日内峰值处理。
- 组合回测的收盘卖出遇尾盘封死跌停时递延；有效盘中风控价继续按既有盘中规则执行，不能绕过一字跌停。组合回测期末未卖出持仓保留估值，不新增强制成交。独立候选模式原有的期末落账统计保持不变，两种模式的期末语义不可混同。
- 分钟仓库返回前复权价格，入场不再重复乘复权比例；涨跌停判断须还原原始价。除权日参考价使用前复权昨收除以当日复权比例，防止后续除权事件污染早期除权日的限价。
- 创业板在 2020-08-24 前采用 10% 限幅（风险警示 5%），此后采用 20%；标量、Polars 与 NumPy 路径统一。历史限价与除权参考价修复升级矩阵缓存版本，保留本地量比时间修正和混合分区时间戳读取能力，旧矩阵不会继续命中。

相关验证位于 `backend/tests/backtest/test_evidence.py`、`test_trailing_peak_close_t_entry.py`、`test_limit_down_close_exit.py`、`test_minute_backtest.py`，以及 `backend/tests/test_price_limits.py` 和 `test_gem_pre_registration_limits.py`。

## 复核修复与补迁（2026-11-06 至 2026-11-07）

复核发现并修复三个集成问题：策略包数字右值在信号页按字符串处理导致崩溃；配置重新保存或启用遗漏分页参数，造成静默少取数据；较晚日期异常经最新缓存入口误拦截更早的历史筛选。回归分别覆盖数值 1／0 与字段条件的展示及启停、导入后保存和启用仍按两页落盘三行、股票／ETF／指数及基准指数异常按目标日期放行或阻断。

同时补齐已确认适用的上游缺项：

- 扩展表固定时刻日／周／月调度、交易日历未知时等待、同日增量游标、表级粒度选择和起始页码编辑。所有配置入口共用模型；采集仍由 collector 执行，共用唯一写入槽，取消释放槽位，写入完成后发布扩展数据更新。
- 龙虎榜缺失或无效 `thscode` 时从有效 `ticker` 规范化，覆盖沪深 B 股与北交所；现有历史缓存读取也使用同一规范化，无法识别的条目跳过并记录。保持精确日期、只读查询及原有详情入口。
- 非矩阵日线参数优化在当前任务内共享依赖面板、行情编码与参数无关的评分因子值，每组独立计算候选、个人叠加、归一化评分和成交。保留财务准备、账号隔离、矩阵／复合／分钟路径和原有资源预算；未引入跨账号或磁盘因子内容缓存。
- 日／分钟 K 批量读取按最多 400 个去重标的串行分块；任一块失败不返回部分成功结果，取消停止剩余请求，每块保留超时。大自选卡片的日 K 只请求视口及缓冲范围，指数继续按原资产类型路由。
- DuckDB 查询各用独立游标，锁只保护游标创建，慢查询不再串行阻塞无关读取；仍保留仓库写入、发布与缓存锁。

性能验证采用相同固定样本与真实回测引擎：30 个标的、260 个交易日、7,800 行、8 组参数，独立执行读取面板 8 次耗时 0.151 秒，共享执行读取 1 次耗时 0.120 秒；40 笔交易、资金曲线及统计一致。另以 2,000 万行计算占用查询连接，三轮短查询等待中位数由 119.618 毫秒降至 0.140 毫秒。以上是受控样本测量，不代表生产行情规模的吞吐保证；实际并发测试另验证慢查询尚未结束时短查询即可返回。

最终验证使用临时数据目录：后端全量 **4,518 项通过、6 项跳过**（370.25 秒）；前端 Vitest **89 个文件、650 项通过**，两份现有 Node 测试另有 **5 项通过**，合计 **655 项**。完整前端构建、87 个改动或新增 Python 文件 Ruff、文档本地链接与 `git diff --check` 通过。首轮全量暴露的财务核验和趋势梯队测试替身已补齐历史截止日参数，专项 78 项及最终全量均通过。保留原有依赖弃用和大体积 chunk 提示。

浏览器使用独立临时环境与模拟数据，检查了 1280 像素桌面和 380 像素窄屏：固定日程、增量、分页起始值、粒度选择、保存按钮及数值信号展示均正常，没有横向溢出；配置保存／启停、查询取消与超时由组件和请求测试覆盖。临时页面及预览进程已清理。未操作真实数据、账号或服务器，版本保持 `0.3.31`，改动保留在 `develop` 工作区，未提交或部署。

剩余上游研究产品项按本地边界处理：稳健参数冠军／平台筛选会增加新的研究评分和选择口径，本地继续使用现有滚动样本外验证；可编程仓位与自动实验室涉及新的执行边界；统一定义目录、源码安装和全站配置搬运会改变个人目录、受信任模板及跨环境白名单。它们不属于此次兼容补迁，不以逐补丁照搬替代本地契约。后续若明确引入对应产品，再分别定义入口、账号归属和验收。

## 适配差异与使用边界

- 策略包遵循[个人声明式策略包](strategy-bundle.md)，导入前预览，不覆盖同 ID 的不同内容；上游任意 Python 源码包会明确拒绝。
- 日 K 自检与修补在“数据 → 高级维护”显式发起；盘后流程只续修已登记的问题，继续遵循[盘后流水线约定](postmarket-pipeline.md)。实际指数／ETF 日线可用性仍由所选源决定，缺能力或空返回不会跨源回退。
- 新图表保留本地特殊图层：业绩断层、缺口、箱体及多空线等开启时使用原 ECharts；普通日 K 与分时采用 Lightweight Charts，详见[功能手册](features.md)。
- [回测抽样核查](strategy.md#回测抽样检查与版本记录)保留实际输入与版本记录，无法证明所有路径均不存在未来数据依赖；缺数据、取消或未完成不会标记通过。
- 五处版本元数据同步：根 `VERSION`、前端包版本、后端项目版本、后端读取兜底和后端锁文件中的本项目版本。改动保留在 `develop` 工作区，未合入 `main`、推送或部署。
